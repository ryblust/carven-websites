# Brand typography

The Carven wordmark and homepage name use Cinzel through the internal CSS family `Carven Display`. The file is the variable-weight (400–700) Latin subset supplied by the Google Fonts CSS API, served locally under the SIL Open Font License 1.1; see `OFL-Cinzel.txt`. The wordmark only uses Latin letters, so no other subsets are bundled.

Source: https://github.com/google/fonts/tree/main/ofl/cinzel

Allura Regular (400) is used for the homepage tagline, served locally under the SIL Open Font License 1.1; see `OFL-Allura.txt`. The CSS family name `Carven Script` is an internal alias for Allura.

Source: https://github.com/google/fonts/tree/main/ofl/allura

The Allura file is the full TrueType resource supplied by the Google Fonts CSS API, without a text subset.

Navigation, prose, and controls use platform system fonts; code uses system monospace.
