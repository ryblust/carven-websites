类型决定一个值可以表示什么、能参与哪些操作。`let count: i32 = 3;` 显式写出类型；省略 `: i32` 时，编译器从初始化器推断。函数参数、结果、字段和集合元素也使用相同的类型写法。

先看类型种类与相同类型的判断，再看期望类型如何影响字面量和构造，最后查阅需要显式 as 的转换。

## 类型身份

`bool`、`char`、`void`、`str`、`String`、有符号整数 `i8/i16/i32/i64/isize`、无符号整数 `u8/u16/u32/u64/usize`、`f32/f64`、`Vector` 与 `Range` 的默认绑定来自 `std::core`；SIMD 向量与掩码的默认绑定来自 `std::simd`。`Operation` 须从 `std::async` 导入。这些名字都遵循普通查找、遮蔽和别名规则，只有结构性语法 `ptr` 额外保留。运行时局部变量不占据类型位置，但会遮蔽表达式中的类型限定符。

每个结构体、类或枚举声明都定义一个独立类型，即使字段完全相同也不因此兼容。这称为名义类型身份。数组身份包含元素类型与长度，切片包含元素类型。非空元组的身份包含有序元素类型、元数与嵌套：`(i32, bool)` 不同于 `(bool, i32)`；`(T,)` 是单元素元组，`(T)` 只是分组。可调用视图 包含参数访问、参数类型、成功结果和失败集合。指针每层包含目标类型与 Read/Write 权限。

普通兼容要求相同规范类型。只有数值字面量、文本、切片、可调用视图 与指针的明确操作支持上下文适配；没有一般数值提升、结构转换或 truthiness。

`void` 是零信息的 单元值 类型，唯一值为 `()`；空元组类型 `()` 与它具有同一规范身份。成功完成的 void 调用产生该值。它可以绑定、传参、存入字段/数组/元组、返回，并用 `()`、通配或绑定模式匹配。默认值为 `()`，两个 单元值 值相等。

```carven
fn finish() {}
fn accept(value: void) {}
let completed: void = finish();
let product: (i32, void) = (7, completed);
let units: [void; 2] = [(); 2];
accept(product.1);
```

生成的 C++ 在普通值位置使用 `carven::runtime::Void`；无失败同步调用的 单元值 结果仍使用原生 C++ `void`，原生导入/导出也如此。异步与可失败完成载体的成功类型同样保留 `void`。源语言成功调用仍产生 `()`。

## 名义类型参数

结构体与载荷枚举支持类型参数及失败集合参数：

```carven
struct Box<T> { value: T }
enum Maybe<T> { None, Some(T) }
let boxed = Box<i32> { value: 7 };
let present = Maybe<i32>::Some(7);
let absent: Maybe<String> = .None;
```

参数只在所属声明内可见，可用于字段、载荷、嵌套名义应用、数组、元组、切片、指针与 Operation。`throw E` 声明失败集合参数，可以进入失败契约，不能充当对象类型。

```carven
import std::async using Operation;
struct Pending<T, throw E> { operation: Operation<T, throw E> }
```

使用 `Box<i32>` 这样的参数化自定义类型时，须显式提供所有实参，并区分类型与失败集合两种参数，如 `Pending<i32, throw Error>` 或 `Pending<i32, throw ()>`。失败集合成员须为可复制的名义载荷类型；`throw ()` 提供空集。定义与有序规范实参共同决定身份。数组长度及声明的失败载荷类型不能依赖类型参数；依赖参数的可调用值签名和原生模板实参不受支持。

定义即使未使用也接受检查。递归应用可转发或置换参数，构造越来越大实参的递归环被拒绝；按值布局环独立检查，指针与切片打断存储环。实例按实际类型使用构造、复制、Take、借用、匹配、默认初始化与相等规则；枚举不产生隐式默认 case。可见性递归检查声明、类型实参与失败集合成员。带操作的参数化类及参数化数值枚举不受支持；没有操作的参数化类保留私有表示。函数支持同样参数种类，并可从公开签名、实参和直接期望结果推断。

## 期望类型

| 位置               | 上下文                        |
| ------------------ | ----------------------------- |
| 带注解的绑定或常量 | 声明类型                      |
| 赋值右侧           | 目标类型                      |
| 实参               | 选定参数类型                  |
| return             | 显式或上下文结果              |
| 字段与枚举载荷     | 对应声明类型                  |
| 数组或元组元素     | 对应元素类型                  |
| 值控制结果分支     | 外围期望结果                  |
| lambda 参数与结果  | 期望 可调用视图，服从显式注解 |

`{ field: value }` 与 `{}` 也使用这些上下文。括号传递外部期望类型，不改变绑定身份，不补写访问标记或捕获，不从后续使用倒推类型。

二元表达式的直接无后缀左数字可从非直接无后缀数字的右侧取得上下文，否则左侧接受外部上下文并提供右侧类型。相等比较的直接 `.Case` 可从非直接 case 的另一侧取得枚举类型，优先于数字规则。此选择不穿透括号、一元或复合表达式，也不改变从左到右求值。

```carven
let length = 3usize;
println(0 + length); // 3
// 单独检查：(0) + length 缺少相同数值类型。
enum Status { Ready, Busy }
let ready: Status = .Ready;
println(.Ready == ready);
```

### 上下文适配

无后缀字面量直接按同数值族期望精度检查；字符串字面量可构造 `String`；`String` 到 `str` 借用文本；数组与 `Vector<T>` 到 `[T]` 借用元素；具体可调用值可适配兼容 view；`ptr<&T>` 可缩小为 `ptr<T>`。这些规则不改变源类型，Write 实参必须有匹配的已有存储。常量完成时保留 `String`，显式 `str` 目的地才保留视图。

## 数值字面量

无后缀整数默认 `i32`，浮点默认 `f64`。期望上下文可在相同整数或浮点族选择能表示该值的类型；后缀固定类型，`char` 不属于数值。

没有期望 `Range<T>` 时，区间边界使用相同相邻操作数选择规则：`0..text.byte_length()` 得到 `Range<usize>`。有期望类型时两端都按 T 检查。两个无后缀端点默认 i32，已有绑定与后缀不改变类型；不兼容或越界边界被拒绝。浮点直接解析为所选精度，不经中间类型。

整数后缀 `ns/us/ms/s` 构造 `std::time` 的普通 `Duration`，字面量本身无需导入；注解或构造中命名 `Duration` 须导入。`100ms` 等于 `Duration { nanoseconds: 100000000 }`。缩放在编译期检查，须落在 i64 纳秒范围，允许 `-9223372036854775808ns`；不支持浮点时长字面量。动态值用 `milliseconds(value)?` 等检查函数。

## `as` 转换表

| 来源     | 目标         | 行为                      |
| -------- | ------------ | ------------------------- |
| 任意类型 | 同一规范类型 | 身份转换                  |
| 整数     | 整数         | 模 `2^N` 后按目标符号解释 |
| 整数     | bool         | 零为 false，其余 true     |
| bool     | 整数         | false 为 0，true 为 1     |
| 整数     | f32/f64      | 原生浮点转换              |
| f32      | f64          | 精度扩宽                  |
| 数值枚举 | 整数         | case 数值                 |
| char     | u32          | Unicode 标量编号          |
| str      | String       | 独立拥有副本              |

浮点到整数/bool、f64 到 f32、bool 到浮点、整数到枚举、其他 char 数值转换及 `String as str` 均无效。后者用目标上下文或 `.as_str()`。指针类型擦除见[指针](/zh/reference/pointers/)。

## 算术与终止

整数取负、加减乘和左移按位宽回绕，复合赋值及自增减同样如此；编译期、解释与原生运行规则一致。有符号最小值除以 -1 得到最小值，余数零；有符号右移为算术右移。除零、负移位或移位量不小于位宽，在编译期执行到时产生诊断，在运行时终止。

```carven
const wrapped: i32 = 2147483647 + 1;
let runtime: u8 = 255u8 + 1;
println(wrapped, runtime); // -2147483648 0
```

字面量仍检查范围，包括符号与括号：`-(2147483648)` 可表示 i32 最小值；`256` 不能初始化 u8。`isize/usize` 依宿主指针模型，目标须匹配；f32/f64 为 IEEE binary32/binary64。语言没有独立舍入模式控制或浮点异常机制，浮点除零依原生规则。

## 浮点方法

f32/f64 的直接 Read 方法无需导入，支持常量、const fn、解释和原生执行。数值参数与结果保持接收者精度，无后缀数字接受该上下文。

| 方法                        | 契约                                              |
| --------------------------- | ------------------------------------------------- |
| `is_finite()`               | NaN 与正负无穷为 false，其他为 true               |
| `abs()`                     | 正幅度，负零变正零，保留 NaN                      |
| `min(other)` / `max(other)` | 传播任一 NaN；数值相等保留接收者，包括零的符号    |
| `clamp(lower, upper)`       | 断言有序且 lower <= upper，保留 NaN 输入          |
| `sqrt()`                    | 保留有符号零和正无穷；负非零、负无穷及 NaN 得 NaN |

clamp 相等边界有效；反序或 NaN 边界触发断言，不产生类型化失败。接收者与实参按源顺序各求值一次，方法不能取为独立值。跨目标位级一致性、NaN 载荷和非默认舍入不保证。

## 数值文本解析

每个标量整数类型和 f32/f64 提供 `T::parse(text: str) -> T throw NumberParseError`。可直接调用并 `?` 传播；命名错误类型时从 `std::core` 导入 `NumberParseError`，其唯一空载荷 case 为 `Invalid`。数值类型别名保留此能力，支持静态、解释与原生执行。

解析消费整个输入并检查范围；空、畸形、不完整、越界输入失败。整数十进制，有符号可带 `-`，无符号连 `-0` 也拒绝；前置空白、`+` 与尾随内容拒绝。浮点接受一般十进制指数、无穷与 NaN，保留零符号，直接按所需精度解析。需要有限值时调用 `is_finite()`。解析独立于 locale，JSON 数字或端口限制属于调用者策略。

```carven
import std::core using NumberParseError;
const fn parse_port(text: str) -> u16 throw NumberParseError => u16::parse(text)?;
const port = parse_port("8080")?;
```

输入 Read 求值一次，结果与错误不借用输入。工厂仅支持直接调用。
