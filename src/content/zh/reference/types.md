类型决定一个值可以表示什么、能参与哪些操作。`let count: i32 = 3;` 显式写出类型；省略 `: i32` 时，编译器从初始化表达式推断。函数参数、结果、字段和集合元素也使用相同的类型写法。

## 类型身份

具名类型遵循[模块名字查找、别名与默认绑定规则](/zh/reference/modules/#标准模块与默认名字)。`ptr` 类型语法还有[额外的命名限制](/zh/reference/keywords/#其他特殊拼写)。

每个结构体、类或枚举声明都定义一个独立类型，即使字段完全相同也不因此兼容。这称为名义类型（nominal typing）。数组类型由元素类型与长度共同决定，切片类型由元素类型决定。非空元组类型由元素类型的顺序、数量与嵌套结构决定：`(i32, bool)` 不同于 `(bool, i32)`；`(T,)` 是单元素元组，`(T)` 只是分组。可调用视图包含参数访问、参数类型、成功结果和失败集合。指针每层包含目标类型与 Read/Write 权限。

通常只有规范化后相同的类型才兼容。数值字面量、文本、切片、可调用视图与指针可按各自规则进行上下文适配；不会自动进行一般的数值提升、结构类型转换，也不会按值是否为零或为空来判断真假。

`void` 是不携带额外数据的单元类型，唯一值为 `()`；空元组类型 `()` 与它具有同一个规范类型。成功完成的 void 调用产生该值。它可以绑定、传参、存入字段/数组/元组、返回，并用 `()`、通配或绑定模式匹配。默认值为 `()`，两个单元值相等。

```carven run
fn finish() {}
fn accept(_: void) {}
let completed: void = finish();
let product: (i32, void) = (7, completed);
let units: [void; 2] = [(); 2];
accept(product.1);
println(units.length()); // 2
```

单元值参数与结果的原生表示见 [C++ 函数接口](/zh/reference/interop/#函数接口声明)。

## 标量类型

这些名字是 `std::core` 的默认绑定。整数宽度包含有符号类型的符号位；有符号整数使用二进制补码算术。

| 类型                      | 宽度与取值                                                                |
| ------------------------- | ------------------------------------------------------------------------- |
| `i8`、`i16`、`i32`、`i64` | 分别为 8、16、32、64 位；`N` 位有符号整数范围是 `-2^(N-1)` 至 `2^(N-1)-1` |
| `u8`、`u16`、`u32`、`u64` | 分别为 8、16、32、64 位；`N` 位无符号整数范围是零至 `2^N-1`               |
| `isize`、`usize`          | 与指针等宽的有符号、无符号整数；分析宿主与目标须使用相同数据模型          |
| `f32`、`f64`              | IEEE 754 binary32 与 binary64，包含正负零、无穷和 NaN                     |
| `bool`                    | `false` 与 `true`；数值和指针不会隐式转为布尔条件                         |
| `char`                    | 一个 Unicode 标量：U+0000..U+D7FF 或 U+E000..U+10FFFF                     |
| `void`、`()`              | 单元类型，唯一值为 `()`                                                   |

[`str` 与 `String`](/zh/reference/text/)分别表示借用的 UTF-8 文本和具有独立存储的 UTF-8 文本；[SIMD 类型](/zh/reference/simd/#类型与模块)定义固定的逻辑通道形状。[数组、元组、结构体、类、枚举和 `Vector<T>`](/zh/reference/aggregates/)、[切片 `[T]`](/zh/reference/slices/)、[指针 `ptr<T>` 与 `ptr<&T>`](/zh/reference/pointers/)、[可调用视图 `fn(...) -> R`](/zh/reference/closures/#可调用视图与生命周期)、[整数区间 `Range<T>`](/zh/reference/operators/#区间表达式)及[操作 `Operation<T, throw E>`](/zh/reference/async/#冷操作与-await)各有对应的构造和访问规则。

## 名义类型参数

结构体与载荷枚举支持类型参数及失败集合参数：

```carven run
struct Box<T> { value: T }
enum Maybe<T> { None, Some(T) }

let boxed = Box<i32> { value: 7 };
let present = Maybe<i32>::Some(7);
let absent: Maybe<String> = .None;
println(boxed.value, present == .Some(7), absent == .None); // 7 true true
```

参数只在所属声明内可见，可用于字段、载荷、嵌套的参数化名义类型、数组、元组、切片、指针与 Operation。`throw E` 声明失败集合参数，可以进入失败契约，不能充当对象类型。

```carven
import std::async using Operation;

struct Pending<T, throw E> { operation: Operation<T, throw E> }
```

使用 `Box<i32>` 这样的参数化名义类型时，显式提供全部实参，区分类型和失败集合，如 `Pending<i32, throw Error>` 或 `Pending<i32, throw ()>`。失败成员须为可复制的名义载荷，`throw ()` 为空集。声明和按顺序规范化的实参共同决定类型。数组长度及声明的失败载荷类型不能依赖类型参数；可调用视图签名可使用类型和失败参数，具名原生模板类型也可使用类型参数，具体原生操作交由 C++ 检查。

定义即使未使用也接受检查。递归可转发或调整参数顺序，导致实参持续扩大的递归会被拒绝。按值存储环独立检查，指针和切片可以打断环。具体实例遵循普通构造、复制、Take、借用、匹配、默认值与相等规则，枚举不隐式选择默认 case。可见性递归检查类型与失败集合实参。类操作继承所属类型的参数并可声明额外参数，按调用实参推断或显式指定；接收者与静态能力规则不变。参数化数值枚举仍不支持。函数可从签名、实参和期望结果推断同样种类的参数。

## 期望类型

| 位置               | 上下文                       |
| ------------------ | ---------------------------- |
| 带注解的绑定或常量 | 声明类型                     |
| 赋值右侧           | 目标类型                     |
| 实参               | 选定参数类型                 |
| return             | 显式或上下文结果             |
| 字段与枚举载荷     | 对应声明类型                 |
| 数组或元组元素     | 对应元素类型                 |
| 值控制结果分支     | 外围期望结果                 |
| lambda 参数与结果  | 期望可调用视图，服从显式注解 |

`{ field: value }` 与 `{}` 也使用这些上下文。括号传递外部期望类型，不改变绑定身份，不补写访问标记或捕获，不从后续使用倒推类型。

二元表达式左侧直接写无后缀数字字面量、而右侧不是这种字面量时，左侧可从右侧获得期望类型。其他情况下，左侧先接受外围的期望类型，再为右侧提供类型。相等比较中，一侧直接写 `.Case` 或 `.Case(...)`、另一侧不是这种写法时，该枚举 case 可从另一侧确定枚举类型；这条规则优先于数字规则。括号、一元表达式或复合表达式内部不适用这种相邻操作数推断；求值顺序仍然从左到右。

```carven run
let length = 3usize;
println(0 + length); // 3
// 单独检查：(0) + length 缺少相同数值类型。
enum Status { Ready, Busy }
let ready: Status = .Ready;
println(.Ready == ready); // true
```

### 上下文适配

期望类型可以选择以下值适配：

| 来源               | 期望类型与结果                             |
| ------------------ | ------------------------------------------ |
| 无后缀数值字面量   | 同一类别的整数或浮点类型中可表示该值的类型 |
| 字符串字面量       | 需要时构造具有独立存储的 `String`          |
| `String`           | 借用的 `str` 视图                          |
| 数组或 `Vector<T>` | 借用的 `[T]` 视图                          |
| 具体可调用值       | 不拥有调用目标的兼容可调用视图             |
| `ptr<&T>`          | `ptr<T>`，缩小目标访问权限                 |

这些适配不改变源的类型。Write 实参需要类型匹配的已有存储。常量求值完成后仍保留 String 自身的存储，显式 `str` 目标才请求视图。文本、切片、可调用值和指针适配仍须满足各自参考中的生命周期和访问要求。

## 数值字面量

无后缀整数默认 `i32`，浮点默认 `f64`。期望上下文可在相同类别的整数或浮点类型中选择能表示该值的类型；后缀固定类型，`char` 不属于数值。

没有期望 `Range<T>` 时，区间边界使用相同的相邻操作数类型推断规则：`0..text.byte_length()` 得到 `Range<usize>`。有期望类型时两端都按 T 检查。两个无后缀端点默认 i32，已有绑定与后缀不改变类型；不兼容或越界边界被拒绝。浮点直接解析为所选精度，不经中间类型。

`ns`、`us`、`ms`、`s` 后缀及带范围检查的时长构造，见[时间](/zh/reference/time/)。

## `as` 转换表

`expression as Type` 支持相同类型之间的转换，以及下表中的数值和文本转换。指针擦除与恢复遵循单独的[指针转换规则](/zh/reference/pointers/#类型擦除比较与显示)；涉及外部 C++ 类型的转换由 C++ 检查。

| 来源     | 目标         | 行为                      |
| -------- | ------------ | ------------------------- |
| 任意类型 | 同一规范类型 | 类型不变                  |
| 整数     | 整数         | 模 `2^N` 后按目标符号解释 |
| 整数     | bool         | 零为 false，其余 true     |
| bool     | 整数         | false 为 0，true 为 1     |
| 整数     | f32/f64      | 原生浮点转换              |
| f32      | f64          | 精度扩宽                  |
| 数值枚举 | 整数         | case 数值                 |
| char     | u32          | Unicode 标量编号          |
| str      | String       | 具有独立存储的副本        |

浮点到整数/bool、f64 到 f32、bool 到浮点、整数到枚举、其他 char 数值转换及 `String as str` 均无效。后者用目标上下文或 `.as_str()`。指针类型擦除见[指针](/zh/reference/pointers/)。

## 算术与终止

整数取负、加减乘和左移按位宽回绕，复合赋值及自增减同样如此；编译期、解释与原生运行规则一致。有符号最小值除以 -1 得到最小值，余数零；有符号右移为算术右移。除零、负移位或移位量不小于位宽，在编译期执行到时产生诊断，在运行时终止。

```carven run
const wrapped: i32 = 2147483647 + 1;
let runtime: u8 = 255u8 + 1;
println(wrapped, runtime); // -2147483648 0
```

字面量仍检查范围，包括符号与括号：`-(2147483648)` 可表示 i32 最小值；`256` 不能初始化 u8。`isize/usize` 依宿主指针模型，目标须匹配；f32/f64 为 IEEE binary32/binary64。语言没有独立舍入模式控制或浮点异常机制。

`f32` / `f64` 的编译期求值和解释执行使用编译器宿主的浮点环境，原生运行使用目标 C++ 工具链的浮点环境。浮点除零按对应环境处理，不触发整数除零诊断。冻结的结果保留其表示；不同目标、舍入模式或优化设置下的运行时计算不保证逐位相同。

## 只读切片

`[T]` 是只读视图，`[T; N]` 是拥有自身存储的固定数组。构造、操作、借用和常量存储见[切片](/zh/reference/slices/)。[`str::from_utf8(bytes)`](/zh/reference/text/) 按相同的生命周期和修改规则借用 `[u8]` 存储。

## 浮点方法

f32/f64 的直接 Read 方法无需导入，支持常量、const fn、解释和原生执行。数值参数与结果保持接收者精度，无后缀数字接受该上下文。

| 方法                        | 契约                                              |
| --------------------------- | ------------------------------------------------- |
| `is_finite()`               | NaN 与正负无穷为 false，其他为 true               |
| `abs()`                     | 绝对值；正零与负零均变为正零，NaN 保持 NaN        |
| `min(other)` / `max(other)` | 传播任一 NaN；数值相等保留接收者，包括零的符号    |
| `clamp(lower, upper)`       | 断言有序且 lower <= upper，保留 NaN 输入          |
| `sqrt()`                    | 保留有符号零和正无穷；负非零、负无穷及 NaN 得 NaN |

clamp 相等边界有效；反序或 NaN 边界触发断言，不产生类型化失败。接收者与实参按源顺序各求值一次，方法不能取为独立值。跨目标位级一致性、NaN 载荷和非默认舍入不保证。

## 数值文本解析

每个标量整数类型和 f32/f64 提供 `T::parse(text: str) -> T throw NumberParseError`。可直接调用并 `?` 传播；命名错误类型时从 `std::core` 导入 `NumberParseError`，其唯一空载荷 case 为 `Invalid`。数值类型别名保留此能力，支持静态、解释与原生执行。

解析会读取整个输入并检查范围；空、畸形、不完整、越界输入失败。整数十进制，有符号可带 `-`，无符号连 `-0` 也拒绝；前置空白、`+` 与尾随内容拒绝。浮点接受一般十进制指数、无穷与 NaN，保留零符号，直接按所需精度解析。需要有限值时调用 `is_finite()`。解析独立于 locale，JSON 数字或端口限制属于调用者策略。

```carven
const port = u16::parse("8080")?;
```

显式失败契约需要命名导入的类型：

```carven
import std::core using NumberParseError;

const fn parse_port(text: str) -> u16 throw NumberParseError => u16::parse(text)?;
```

输入 Read 求值一次，结果与错误不借用输入。这些解析函数仅支持直接调用。
