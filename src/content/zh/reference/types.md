## 类型身份

内建类型为 `bool`、`char`、`str`、`String`、`void`，有符号整数 `i8/i16/i32/i64/isize`，无符号整数 `u8/u16/u32/u64/usize`，以及 `f32/f64`。

结构体和枚举由声明身份决定类型；相同字段不意味着兼容。数组类型同时包含元素类型和长度；切片包含元素类型。callable view 类型包含参数访问、参数类型、成功结果和失败集合。指针的每一层包含目标类型和 Read/Write 目标权限。

普通 Carven 值要求相同规范类型。语言仅在明确支持的位置进行字面量、文本、切片、callable 和指针转换，没有通用数值提升、结构转换或 truthiness。

`void` 表示没有值，只能作为成功结果等允许无值的位置。它不能作为参数、字段、数组元素、运行时绑定或 match 主体。`action();` 可调用 void 函数；`let x = action();` 非法。

## 期望类型

| 位置                 | 类型上下文来源                   |
| -------------------- | -------------------------------- |
| 带注解的绑定、常量   | 声明类型                         |
| 赋值右侧             | 目标类型                         |
| 实参                 | 选定参数类型                     |
| return               | 显式或上下文提供的结果类型       |
| 字段、枚举载荷       | 对应声明类型                     |
| 已有数组上下文的元素 | 数组元素类型                     |
| 值控制分支           | 外围提供的结果类型               |
| lambda 参数和结果    | 期望 callable view，服从显式注解 |

括号传递已有上下文。上下文不会改变绑定的类型，不会补写访问标记或捕获。运行时绑定推断后不因后续用途改变类型；不存在为所有使用点统一搜索一个可行类型的推断。

二元表达式中，若左侧是直接无后缀数字而右侧不是，数字可从右侧取得上下文；否则左侧接受外围上下文并给右侧提供类型。相等比较中的直接 `.Case` 可从非直接 case 的另一侧取得枚举类型，这条优先于数字规则。逻辑运算要求 bool。

这些规则只检查直接操作数，不穿透括号、一元或复合表达式寻找字面量。类型上下文的选择不改变运行时从左到右求值。

## 数值字面量

无后缀整数默认 `i32`，浮点默认 `f64`。期望数值上下文可以选择同一整数或浮点族中能表示该值的类型；显式后缀固定类型。`char` 不是数值类型。

```carven
let small: u8 = 12;
let real: f32 = 1.5;
let wide = 12i64;
// 编译错误：已确定为 i64 的值不能隐式变成 i32。
let narrow: i32 = wide;
```

## `as` 转换表

当两边都是 Carven 类型时，允许：

| 来源     | 目标         | 结果                      |
| -------- | ------------ | ------------------------- |
| 任意类型 | 同一规范类型 | 身份转换                  |
| 整数     | 任意整数     | 模 `2^N` 后按目标符号解释 |
| 整数     | bool         | 零为 false，其余为 true   |
| bool     | 整数         | false 为 0，true 为 1     |
| 整数     | f32、f64     | 对应原生浮点转换          |
| f32      | f64          | 浮点扩宽                  |
| 数值枚举 | 任意整数     | 使用 case 的数值          |
| char     | u32          | Unicode 标量编号          |
| str      | String       | 独立拥有的文本副本        |

不允许 f64 到 f32、浮点到整数或 bool、bool 到浮点、整数到枚举、其他 char 数值转换，也不能使用 `String as str`。String 到 str 使用目标上下文或 `.as_str()`。

## 算术与终止

运行时整数取负、加减乘、左移按类型宽度回绕；复合赋值和自增减同样如此。有符号最小值除以 -1 得到最小值，余数为零。有符号右移是算术右移。除数为零、余数除数为零、移位量为负或不小于宽度时终止。

必需常量求值的整数运算检查溢出，不使用回绕结果。即使初始化目标是运行时 `let`，可证明溢出的字面量运算也会报错。字面量取负连同符号检查，包括括号：`-(2147483648)` 可表示 i32 最小值。

`isize/usize` 的宽度由宿主指针数据模型决定，目标必须匹配。`f32/f64` 为 IEEE 754 binary32/binary64。浮点运行行为由原生 C++ 运算和浮点环境决定，语言没有独立的舍入模式控制或浮点异常机制；浮点除零遵循原生浮点规则。
