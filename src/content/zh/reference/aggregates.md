把相关数据组合起来时，可以按用途选择：struct 为字段命名，元组按位置保存不同类型，数组固定长度，Vector 可以增长，enum 表示几种可能情况。class 则在字段外提供操作，控制外部如何使用数据。

## 结构体

结构体把一组相关的值放在一起，并用字段名访问。字段的类型由声明确定，构造时为每个字段提供一个值。需要公开数据时用 struct；需要通过操作控制字段访问时用 class。

```carven
struct Endpoint { host: String, port: u16 }
fn endpoint() -> Endpoint => { port: 8080, host: "localhost" };
```

## 普通值类

类保存一个普通值，字段只能在类内部访问。它不会因为使用 class 就自动变成堆对象，也不引入继承或虚派发。复制和转移仍遵循普通值规则。字段只在类体可访问，未写 private 的操作与类使用相同可见范围，`private fn` 仅类体可访问。操作与字段共用唯一名字空间，不支持重载或隐式 self 查找。

```carven
class Counter {
    value: i32,
    const fn new(value: i32) -> Counter => { value: value };
    const fn read(self) -> i32 => self.value;
    fn increment(&self) { self.value += 1; }
}
const initial = Counter::new(3);
var counter = initial;
counter.increment();
println(counter.read()); // 4
```

`Type::new` 是普通关联工厂的惯例，不提供隐式调用或生命周期行为；特定工厂保留 `parse/open/from_str` 等名字。没有接收者参数的操作通过 `Type::name(...)` 调用；同步关联操作也能作为可调用值使用。实例用 `value.name(...)`，接收者求值一次且先于显式实参。首参数 `self/&self/&&self` 无类型注解，分别使用 Read/Write/Take；实例操作不能取为独立值。

关联操作可为 async，使用冷 operation 与 await 规则；带实例接收者的 async 操作不支持。类可有 const fn 操作，适用普通能力、私有可见性及冻结规则；类内局部常量保留该类的表示访问权。嵌套声明、类表示模式及 C++ 导入/导出操作不支持。类没有默认值，也不支持相等；结构显示只显示类名。

## 上下文构造

已知期望结构体或可访问类类型时，`{ field: value }` 可省略类型；`{}` 请求整个类型的默认初始化。上下文来自注解、实参、返回、字段、数组/元组元素和结果分支。无上下文时省略类型非法；上下文构造不能写位置参数，显式 `Type { ... }` 可按字段声明顺序写位置参数。非空构造必须完整初始化所有字段，不能混用位置和名字。具名初始化按书写顺序求值，不按字段顺序。

## 默认初始化

| 类型                   | 默认值                                         |
| ---------------------- | ---------------------------------------------- |
| bool、整数、浮点、char | false、零、正零、U+0000                        |
| str / String           | 空文本；String 独立拥有                        |
| ptr                    | 空地址，仍适用非空检查                         |
| 切片                   | 空只读切片                                     |
| Vector                 | 空拥有序列，不要求元素有默认值                 |
| Range                  | 从零到零的空半开区间                           |
| void                   | `()`                                           |
| 非空元组、结构体       | 每个元素/字段递归默认初始化                    |
| 固定数组               | 每个元素独立默认初始化；零长度不要求元素默认值 |
| 原生 C++ 类型          | 由 C++ 检查的原生值初始化                      |

类、枚举和可调用值无默认值；包含这些成员的结构体或非空数组也无默认值。`CV-TYPE-DEFAULT-INITIALIZATION` 标识不可用的默认构造。泛型 `Vector<T>` 与 `[T; 0]` 不要求未知 T 有默认值。

## 固定数组

数组类型 `[T; N]` 有固定元素类型和编译期非负长度。`[a, b]` 在没有期望上下文时推断非空数组；期望数组要求精确长度，期望切片借用对应存储，期望 Vector 则构造拥有向量。`[]` 需要 `[T; 0]`、`[T]` 或 `Vector<T>` 上下文。零长度数组形成的空切片不保留 后备存储。

`[expression; N]` 按索引顺序把表达式重新求值 N 次，每次有普通访问与寿命规则。N 为零时仍检查表达式并取得类型，但不执行；不要求元素默认值。中途失败停止后续元素并清理已完成元素。展开受构造预算限制。

```carven
var next = 0;
let generate = [&next]() -> i32 { next += 1; return next; };
let samples = [generate(); 4];
println(samples.length(), samples[3]); // 4 4
```

数组直接提供 `length()` 与 `is_empty()`，接收者及其效果/失败仍求值一次。索引为整数；已知越界在分析期诊断，动态越界确定性终止。接收者先于索引且各求值一次。写元素要求可写接收者。消费整个数组后选元素会交付独立值；已有数组存储的索引遵循 Read 复制规则；切片总是选择借用元素，即使 descriptor 被消费。

数组按元素支持相等，包括零长数组仍要求元素类型支持相等；结构体无相等。名义类型不可经字段、载荷、数组形成按值存储环，零长数组仍贡献元素边；函数签名不贡献存储边。

## 元组

元组是有序异构积，类型和值分别如 `(i32, str)` 与 `(20, "answer")`。嵌套层次保留，元素从左到右各求值一次，已有元组上下文按位置提供类型。`(x)` 分组，`(x,)` 单元素，`()` 为 void 单元值。非空元组中的 void 保留逻辑位置。

```carven
var (number, _, (text,)): (i32, void, (str,)) = (42, (), ("ready",));
number += 1;
println(number, text); // 43 ready
```

局部 let/var/const 接受递归元组目标，要求元素数量与嵌套层次一致。运行时每个名字成为声明对应可变性的完整 所有者，Take 一个名字不影响同级名字。`let (a, b) = owner` 复制，`let (a, b) = &&owner` 消费整个源 所有者。初始化器求值一次，元素存储稳定到绑定作用域结束，丢弃元素也活到该时刻。局部 const 将源冻结一次后绑定对应常量元素。

位置字段为 `pair.0`、`nested.1.0`、`pair.0.method()`；位置使用无前导零/下划线/后缀/指数的十进制。越界包括在 `()` 上选位置均分析期拒绝。元组没有动态索引；指针 `p->0` 等于 `(*p).0`。

位置字段继承 Read/Write，接收者只求值一次；不能从可用完整所有者写 `&&pair.0`。`(&&pair).0` 先消费完整元组再交付字段，剩余元素在完整表达式结束时清理。

函数/lambda 参数可用递归元组目标，仍是一个完整的元组参数。Read/Write 名字投影参数的现有存储，Take 名字为独立不可变 所有者。静态参数保留静态值规则。范围循环可分解数组或切片中的元组元素，继承当前元素访问且不可 Take；这不使元组本身可迭代。元组及枚举载荷模式递归匹配，`()` 匹配 单元值、`(p)` 分组、`(p,)` 匹配单元素。

## 拥有向量

`Vector<T>` 深度拥有连续已初始化元素，支持独立复制、整个所有者的 Take、检查过的 Read/Write 索引和迭代。递归结构体与枚举可含自身类型的 Vector。原始指针元素仍只复制地址。

```carven
var numbers: Vector<i32> = [10, 20, 30];
numbers.push(40);
let removed = numbers.remove(1);
let tail: [i32] = numbers.slice(1, 3);
println(removed, tail[0]); // 20 30
```

| 操作                            | 规则                                 |
| ------------------------------- | ------------------------------------ |
| `Vector<T>::new()`              | 空 所有者，容量零                    |
| `from_slice(values: [T])`       | 独立复制元素                         |
| `with_capacity(minimum)`        | 空 所有者，至少该容量                |
| `length()` / `is_empty()`       | Read，usize / bool                   |
| `capacity()`                    | Read，元素容量                       |
| `reserve(minimum)`              | Write，确保总容量至少为 minimum      |
| `push(value)` / `push(&&value)` | Write，复制或转移末尾元素            |
| `remove(index)`                 | Write，返回移除 所有者，保持剩余顺序 |
| `clear()`                       | Write，销毁元素并保留容量            |
| `slice()` / `slice(start, end)` | Read，借用完整或半开子范围           |

字面量在 Vector 上下文中构造 Vector，已有数组/切片须用 from_slice。`Vector<T> {}` 与 `{}` 默认空序列，不要求元素默认值。增长因子未规定；容量内追加不重分配，remove/clear 保留容量，复制不承诺相同空余容量。分配失败与容量溢出终止，不产生声明的失败。

Vector 可直接适配 `[T]`。活切片保护整个 所有者，禁止写入、替换、Take、销毁或结构变更，即使保留容量足够也如此。Read/Write 遍历都禁止结构变更，Write 可更新元素。不能 Take 索引元素，用 remove 提取。从同一个 Vector 的元素向末尾 push 时，允许的调用会先复制实参，再修改存储。

Vector 的元素必须能独立拥有自己的内容；借用文本、切片、可调用值、原生 C++ 值、异步操作 及包含这些值的元组或结构体均不能作元素。原始指针保留目标契约；`Vector<bool>` 有普通元素与 [bool] 视图。没有裸指针提取或未初始化存储 API。

构造、复制、Take、修改、移除、切片及容量操作支持原生、解释与静态执行。常量保留 Vector 类型、拥有权、内容及容量；完成时保留的切片有不可变静态 后备存储。复制保留 Vector 后再修改会创建独立内容，预算限制存储、容量和工作。

## 两类枚举

枚举为名义和类型。无底层类型的枚举可有空载荷或位置载荷 case，按相同的元素数量构造并以模式匹配。带整数底层类型的数值枚举为 case 定义数值，可 `as` 转为整数，不能由整数直接转回。`.Case` 需要上下文提供枚举身份。枚举无默认 case；同 case 的可相等载荷按位置短路比较，不同 case 不等。

## 递归存储与可见性

结构体/枚举的按值存储图须无环，指针、切片与 Vector 可以打断递归存储。公开声明的表面及嵌套类型须对该受众可见；类私有字段保留其表示封装规则。
