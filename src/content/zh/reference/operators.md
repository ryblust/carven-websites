## 运算符总览

表达式计算一个值；赋值和自增减是更新存储的动作，只能出现在允许它们的语句或 `for` 头部。下表中的操作数要求适用于 Carven 类型；外部 C++ 类型按原生操作规则处理。

| 类别   | 拼写                         | 操作数与结果                                             |
| ------ | ---------------------------- | -------------------------------------------------------- |
| 算术   | `+` `-` `*` `/`              | 相同数值类型，得到该类型                                 |
| 余数   | `%`                          | 相同整数类型                                             |
| 前缀   | `-` `!` `~`                  | 数值取负、布尔取反、整数按位取反                         |
| 位运算 | `&` `\|` `^` `<<` `>>`       | 整数操作                                                 |
| 排序   | `<` `<=` `>` `>=`            | 相同数值类型，得到 `bool`                                |
| 相等   | `==` `!=`                    | 兼容且支持相等的类型，得到 `bool`                        |
| 逻辑   | `&&` `\|\|`                  | `bool` 操作数，从左向右短路                              |
| 转换   | `as`                         | 按[转换表](/zh/reference/types/#as-转换表)执行显式转换   |
| 区间   | `..` `..=`                   | 整数端点，得到 `range<T>`                                |
| 访问   | `&` `&&`                     | Write 或 Take 访问，见[所有权](/zh/reference/ownership/) |
| 后缀   | `(...)` `[...]` `.` `->` `?` | 调用、索引、成员访问、指针成员、失败传播                 |

```carven
let total = 2 + 3 * 4;
let allowed = total >= 10 && total < 20;
println(total, allowed); // 14 true
```

不自动把整数提升到另一种整数或浮点类型，也不把数字当作布尔条件。字面量可以从期望类型取得类型，已有变量不会因运算而变成另一种类型。

## 优先级与括号

下表从高到低排列。重复形式的普通二元运算与 `as` 左结合。比较运算共用一个不可结合的级别：写 `a < b && b < c`，不能写 `a < b < c`。

| 优先级 | 操作                              |
| ------ | --------------------------------- |
| 最高   | 后缀调用、索引、成员访问、`?`     |
|        | 前缀 `-` `!` `~` `*`              |
|        | `as`                              |
|        | `*` `/` `%`                       |
|        | `+` `-`                           |
|        | `<<` `>>`                         |
|        | `<` `<=` `>` `>=` `==` `!=`       |
|        | 二元 `&`                          |
|        | `^`                               |
|        | 二元 `\|`                         |
|        | 逻辑 `&&`                         |
|        | 逻辑 `\|\|`                       |
|        | `..` `..=`                        |
| 最低   | 位于表达式起点的访问标记 `&` `&&` |

访问标记覆盖右侧完整表达式。例如 `&&value` 表示 Take，`left && right` 表示逻辑与。括号可以明确作用范围。没有逗号表达式；完整产生式见[语法附录](/zh/reference/grammar/#优先级)。

## 赋值与更新

```text
target = expression;
target += expression;
++target;
--target;
```

赋值目标必须可写。复合赋值包括 `+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`^=`、`<<=`、`>>=`；它们读取旧值再写回。自增减只有前缀形式。赋值、自增减不产生表达式值，不能作为普通函数实参或初始化器。

```carven
var count = 1;
count += 2;
++count;
println(count); // 4
```

```carven
var count = 1;
let changed = ++count; // 编译错误：更新不是表达式。
```

## 短路与求值次序

逻辑与在左侧为 `false` 时跳过右侧，逻辑或在左侧为 `true` 时跳过右侧。这只决定运行时求值；两边的源码都接受类型、访问与失败契约检查。

```carven
fn report() -> bool {
    println("called");
    return true;
}

let result = false && report();
println(result); // false；不会输出 called。
```

callee 在实参之前、左操作数在右操作数之前、接收者在索引之前、赋值目标在右侧之前。构造初始化器按源书写顺序求值。当前路径上的每个操作数只求值一次；失败跳过该路径后续求值。静态实参另按[静态参数规则](/zh/reference/functions/#静态参数)在特化时求值。

## 相等比较

相等支持 `bool`、`char`、整数、浮点、`str`、`String`、元素可比较的数组、数值枚举、载荷可比较的载荷枚举，以及相同目标类型的指针。结构体、类、callable、入口参数、切片、整数区间和 chars 范围不支持相等。

```carven
println("same" == "same", [1, 2] == [1, 2]); // true true
```

浮点比较遵循 IEEE，`!=` 是 `==` 的否定。SIMD 比较按[向量与掩码规则](/zh/reference/simd/#运算符与掩码)产生掩码。不支持的类型比较报告 `CV-TYPE-EQUALITY-UNSUPPORTED`。

## 整数算术与失败

整数取负、加减乘、左移按类型宽度回绕；复合赋值和自增减同样如此。有符号最小值除以 -1 得到最小值，余数为零；有符号右移为算术右移。

除数或余数除数为零，以及移位量为负或不小于类型宽度，都会在运行时终止。在必需的编译期执行中，则在实际执行到操作时产生诊断。这些终止不能用 `try` / `catch` 捕获为类型化失败。详见[算术与终止](/zh/reference/types/#算术与终止)。

## 区间表达式

`begin..end` 不包含上端点，`begin..=end` 包含上端点，两者都是 `range<T>`。普通表达式必须有两个整数端点；省略端点只允许用于模式。区间值保存端点的快照，不借用原始端点。

```carven
var end = 4;
let values: range<i32> = 1..=end;
end = 8;
for value in values {
    println(value);
}
```

依次输出 1 到 4。端点各从左向右求值一次；已有期望类型 `range<T>` 时，两端使用 T；否则按[二元操作数的期望类型规则](/zh/reference/types/#期望类型)选择 T，例如 `0..text.len()` 为 `range<usize>`。不兼容的端点报告 `CV-TYPE-RANGE-BOUNDS`。不支持步长或隐式反向遍历。循环与区间模式见[控制流](/zh/reference/control/)。
