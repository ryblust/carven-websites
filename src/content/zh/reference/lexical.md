## 源文本

Carven 词法分析的源文本使用 UTF-8。标识符使用 ASCII：首字符为字母或 `_`，后续可为字母、数字或 `_`。中文可以出现在注释、字符串和 C++ 头文件名中。命名风格不改变语法合法性。

空白包括空格、制表符、LF、CR 和 CRLF。行注释从 `//` 到行末；普通 Carven 源码不支持块注释。`#[cpp]` 内的内容按原始字节处理，不按 Carven 语法解析。

保留关键字、上下文用法与命名限制见[关键字索引](/zh/reference/keywords/)。

## 数字

| 形式       | 示例                     |
| ---------- | ------------------------ |
| 十进制整数 | `42`、`42i64`、`10usize` |
| 十六进制   | `0xff`、`0XFFu32`        |
| 二进制     | `0b1010`                 |
| 八进制     | `0o17`                   |
| 小数       | `1.25`、`1.25f32`        |
| 指数       | `1e3`、`1.5E-2`          |
| 仅浮点后缀 | `1f32`、`1f64`           |

正负号是前缀运算符。后缀紧邻字面量；整数后缀使用[整数类型名](/zh/reference/types/#标量类型)，浮点后缀是 `f32` 和 `f64`。没有 C++ 的 `f`、`l`、`ul` 后缀，也没有数字分隔符语法。小数点形式要求点两侧都有十进制数字。

整数后缀 `ns`、`us`、`ms`、`s` 构造 `std::time` 的普通 `Duration` 值，例如 `100ms` 或 `2s`。十进制、十六进制、二进制和八进制整数写法均可使用这些后缀。缩放到 `i64` 纳秒时在编译期检查范围；字面量本身无需导入，显式命名 `Duration` 时仍须从 `std::time` 导入。见[时间](/zh/reference/time/)。

## 字符和字符串

字符字面量使用单引号，解码后恰好包含一个 Unicode 标量；普通字符串使用双引号。支持 `\'`、`\"`、`\\`、`\n`、`\t`、`\r`、`\0` 和 `\u{...}`。Unicode 转义使用一至六个十六进制数字，值不超过 U+10FFFF，且不属于代理项 U+D800..U+DFFF。没有 `\xNN`、`\uXXXX` 或 `\UXXXXXXXX`。

字符和单行字符串必须在起始行结束。普通字符串也支持多行 `"""..."""`；原始字符串使用 `r"..."`、`r#"..."#` 或相应三引号形式。原始内容逐字保留反斜线和花括号，不处理转义或插值；匹配的井号用于区分结束定界符与正文。不进行 Unicode 归一化，也不隐式拼接相邻字面量。[多行布局规则](/zh/reference/text/#字符串字面量与多行布局)定义边界、公共缩进与换行归一化。

```carven
const scalar = '我';
const text = "第一行\n第二行";
const nul = "a\0b";
```

`c"..."` 的 c 必须紧贴引号，结果是原生 `const char*`；解码后内部 NUL 非法。C 字符串只有带转义的单行形式；`c "..."`、原始形式、多行形式和组合前缀都不是 C 字符串字面量。

`f"..."` 和多行 `f"""..."""` 产生具有独立存储的 `String`。`{{`、`}}` 表示字面花括号。插值占位符包含普通表达式及可选的 `:` 格式说明；动态宽度和精度也使用占位符。只有占位符顶层且不属于 `::` 的冒号才开始格式说明。占位符内可包含括号、字符串、嵌套插值和普通换行；占位符不能为空。解码后的转义不再次扫描为插值定界符。前缀必须紧贴定界符；其他位置的 `r`、`f` 是标识符，`fr`、`rf`、`cr` 不是组合字符串形式。

## C++ 头文件与源片段

`import` 后的 `<...>` 或 `"..."` 是专门的非空头文件名 token；中间可有空白或行注释。头文件名不解码转义、不插值，不能包含换行或 NUL。

```carven
import <cstdint>;

#[cpp] ---
int native_answer() {
    return 42;
}
---
```

`#[cpp]` 内部不能有空白。它后面至少有一个空格或制表符，接至少三个 `-`，再接换行。结束围栏独占一行，可缩进，横线数与开始围栏完全相同。匹配行即结束，即使该行看起来位于 C++ 字符串或注释内部。C++ 片段内容可以为空，结束后不加分号。

## 分隔符和消歧

模块导入连续放在文件开头。函数块体不带结尾分号，表达式体 `=> expression;` 带分号。绑定、赋值、控制转移和普通表达式语句以分号结束。`if`、`match`、`try` 的值分支以末尾表达式产生值；这不是普通函数块的隐式返回。

赋值和自增减是语句动作，不是表达式；自增减使用前缀形式。没有独立的 `{ ... }` 块语句或类型别名声明；(value) 分组，(value,) 是单元素元组，() 是单元值。

在表达式位置，`{ field: value }` 与 `{}` 是根据上下文确定类型的构造表达式。在 match 或 catch 分支体开头，`{` 后紧跟 `IDENTIFIER :` 时开始构造；其他开头的花括号，包括 `{}`，都开始分支块。空构造分支写作 `({})`。函数体、if 体和 try 体始终是块。解析器只依据 token 判断，不做名字或类型查找。`&`、`&&` 在参数和实参位置表示访问；在普通表达式中，`&&` 也可表示 Take 或二元逻辑与，取决于位置。词法采用最长匹配，泛型类型中的连续 `>` 由类型解析规则处理。

`..` 与 `..=` 各自按最长匹配识别为一个 token，分别表示半开与闭区间。区间表达式必须有两端；省略端点的写法只用于区间模式。
