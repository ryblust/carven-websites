## 源文本

Carven 词法分析的源文本使用 UTF-8。标识符使用 ASCII：首字符为字母或 `_`，后续可为字母、数字或 `_`。中文可以出现在注释、字符串和 C++ 头文件名中。命名风格不改变语法合法性。

空白包括空格、制表符、LF、CR 和 CRLF。行注释从 `//` 到行末；普通 Carven 源码不支持块注释。`#[cpp]` 的载荷按不透明字节处理。

保留关键字如下：

```text
as break catch const continue else enum export false fn for if import in is let
match nullptr private rethrow return struct test throw true try using var while
```

`new`、`delete` 等没有语言产生式的拼写仍是普通标识符。`_` 在绑定位置表示丢弃；`_name` 是普通名字。

## 数字

| 形式       | 示例                     |
| ---------- | ------------------------ |
| 十进制整数 | `42`、`42i64`、`10usize` |
| 十六进制   | `0xff`、`0XFFu32`        |
| 二进制     | `0b1010`                 |
| 八进制     | `0o17`                   |
| 小数       | `1.25`、`1.25f32`        |
| 指数       | `1e3`、`1.5E-2`          |
| 仅浮点后缀 | `1f32`、`1f64`           |

正负号是前缀运算符。后缀紧邻字面量；整数后缀是 `i8/i16/i32/i64/isize/u8/u16/u32/u64/usize`，浮点后缀是 `f32/f64`。没有 C++ 的 `f`、`l`、`ul` 后缀，也没有数字分隔符语法。小数点形式要求点两侧都有十进制数字。

## 字符和字符串

字符字面量使用单引号，解码后恰好包含一个 Unicode 标量；普通字符串使用双引号。支持 `\'`、`\"`、`\\`、`\n`、`\t`、`\r`、`\0` 和 `\u{...}`。Unicode 转义使用一至六个十六进制数字，值不超过 U+10FFFF，且不属于代理项 U+D800..U+DFFF。没有 `\xNN`、`\uXXXX` 或 `\UXXXXXXXX`。

字面量在开始的行内结束；不做 Unicode 归一化。相邻字符串不会自动拼接。

```carven
const scalar = '我';
const text = "第一行\n第二行";
const nul = "a\0b";
```

`c"..."` 的 `c` 必须紧邻引号，生成原生 `const char*`，解码后的内部 NUL 非法。`c "..."` 不是一个字面量。它没有 raw 形式。

`f"..."` 是插值表达式，结果是 String。`{{` 和 `}}` 表示字面大括号。孔包含普通表达式和可选 `:` 格式说明；动态宽度和精度也使用孔。只有孔顶层且不属于 `::` 的冒号开始格式说明。孔内可包含括号、字符串、嵌套插值和普通换行；空孔非法。转义解码结果不会再次作为插值分隔符扫描。

## C++ 头文件与源片段

`import` 后的 `<...>` 或 `"..."` 是专门的非空头文件名 token；中间可有空白或行注释。头文件名不解码转义、不插值、不跨行。

```carven
import <cstdint>;

#[cpp] ---
int native_answer() {
    return 42;
}
---
```

`#[cpp]` 内部不能有空白。它后面至少有一个空格或制表符，接至少三个 `-`，再接换行。结束围栏独占一行，可缩进，横线数与开始围栏完全相同。匹配行即结束，即使该行看起来位于 C++ 字符串或注释内部。载荷可以为空，结束后不加分号。

## 分隔符和消歧

模块导入连续放在文件开头。函数块体不带结尾分号，表达式体 `=> expression;` 带分号。绑定、赋值、控制转移和普通表达式语句以分号结束。`if`、`match`、`try` 的值分支以末尾表达式产生值；这不是普通函数块的隐式返回。

赋值和自增减是语句动作，不是表达式；自增减使用前缀形式。没有独立的 `{ ... }` 块语句、元组或类型别名声明。`&`、`&&` 在参数和实参位置表示访问；在普通表达式中，`&&` 也可表示 Take 或二元逻辑与，取决于位置。词法采用最长匹配，模板类型中的连续 `>` 由类型解析规则处理。
