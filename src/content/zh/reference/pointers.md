## 地址值与目标访问

指针保存地址，用于访问其他地方的值；它不拥有目标，也不让目标额外存活。`ptr<T>` 允许读取目标，`ptr<&T>` 还允许修改目标。两者可空且可复制，不拥有目标。let/var 控制指针变量的重新赋值，不改变目标权限：let p: `ptr<&T>` 仍可写目标。Read 聚合保留其指针字段的完整目标权限。

目标用普通类型解析，可为 Carven、原生类型或嵌套指针。原生别名的底层种类由 C++ 判定。指针字段不贡献按值存储环。`ptr<void>` 可存储传递，但不能解引用。

## 使用 `addressof` 取地址

`addressof(place)` 返回 `ptr<T>`；`addressof(&place)` 在 place 可写时返回 `ptr<&T>`。该内建名字可被遮蔽，但必须直接调用，不能保存或适配为可调用值。place 仅求值一次，不接受临时、局部常量或 Take。新地址已知非空。

```carven run
var count = 1;
let pointer = addressof(&count);
*pointer += 2;
println(count); // 3
```

对仍存活的所有者赋值不会改变其地址；Take 会使原对象失效，后续重新赋值也不会让旧指针重新有效。Read 数组参数返回的地址可能指向调用者存储；实参为临时数组时仅活到包含调用的完整表达式，保存地址不延长生命周期。

## 转换与实参

`*p` 表示指针指向的存储位置，`p->member` 等于 `(*p).member`。地址须可用并局部证明非空；权限来自指针类型。`let value = *p` 普通初始化值，原生可复制性由 C++ 检查。`&*p` 可传 Write；`&&*p` 非法，因为目标不是具有所有权的 Carven 绑定。

间接地址不建立跟踪借用。Read 已有可调用视图复制目标描述；把通过指针读出的捕获闭包适配为新视图时，仍须能够跟踪其底层存储。间接调用不会重新建立捕获关系，也不会证明目标对象的生命周期。

相同目标 T 的 `ptr<&T>` 可在初始化、赋值、聚合元素、Read 实参、常量与返回等值上下文变 `ptr<T>`，反向无效。这不提供数组、聚合、嵌套目标或函数类型协变。每层独立，透过外层 Read 指针复制的内层指针保持自己的权限。上下文不明的混合权限数组或分支需注解；nullptr 可从相邻类型定型，但不能借此缩小嵌套元素权限。

Read 指针参数保存地址快照。Write 参数引用调用方保存地址的存储位置，须完整类型相同；Take 也须类型精确相同，转移地址值并令源所有者不可用，不会清空其他别名或释放目标。

## 类型擦除、比较与显示

显式 `as ptr<void>` 擦除对象目标类型。Write 指针可变 `ptr<&void>` 或缩小成 `ptr<void>`；Read 只能擦成 `ptr<void>`。显式 as `ptr<T>` 按同样权限规则恢复目标，保留地址及其原有的生命周期关系。Carven 的可调用值也是对象；已知原生 const char* 的 C 字符串也可擦成 `ptr<void>`。

```carven run
var value = 42;
let erased = addressof(&value) as ptr<&void>;
let restored = erased as ptr<&i32>;
if restored != nullptr {
    println(*restored);
}
```

原生转换用 C++ static_cast。恢复后的使用要求对齐、对象类型、别名与生命周期符合要求；转换本身不访问或构造对象。静态/解释解引用要求在保留地址上找到仍存活且类型匹配的对象，否则报告执行诊断。

nullptr 需要指针上下文，没有独立 null 类型。指针支持与 nullptr 及相同目标类型指针的 ==/!=，没有隐式 bool、排序、算术、直接索引或整数转换。比较按地址。静态/解释执行记录存储来源与子对象路径；对于数值、bool、char、指针，以及递归包含这些类型的结构体，支持标准布局对象与首字段地址相同的规则。数组容器、元组和文本缓冲区 的地址关系依赖表示，不能建立关系则报告执行诊断；原生使用生成 C++ 的关系。

擦除指针接受空格式或 p。静态非空/空分别格式化为 const@nonnull/const@null，这些字符串没有对象身份，可普通计算并冻结；非空指针本身仍不能保留为常量结果。解释执行用 interp@object#N 等本次执行地址标签，同地址同标签，无法建立地址键则诊断；原生执行使用 C++ 指针格式化器。显示地址不延长生命周期，不证明可解引用。

## 局部非空证明

解引用可空指针前，先检查它是否非空。每个函数独立建立自己的非空条件，即使调用者通过 `addressof` 取得了指针：

```carven run
fn increment_if_present(target: ptr<&i32>) {
    if target != nullptr {
        *target += 1;
    }
}

var count = 2;
let address = addressof(&count);
increment_if_present(address);
increment_if_present(nullptr);
println(count); // 3
```

每个函数/闭包独立跟踪局部名、固定 Carven 字段路径、常量数组索引的空/非空/未知事实。与 nullptr 比较、取反、短路与提前返回可细化路径，汇合保留共同事实。bool 帮助函数、API 成功码和测试断言不是证明。泛型定义未实例化也检查同样规则。

地址复制与缩小权限携带当前事实但不建立持久等式；赋值替换事实，Take 删除源事实。Write 调用清除重叠槽事实；可能从 Write 参数逃逸的槽、Write 参数与 Write 捕获会被后续调用清除事实。循环在检查条件/循环体前清除可能写入的事实，不推导跨迭代关系。

原生对象成员访问、动态索引或通过指针访问的存储不保留跨表达式事实，应先保存到局部变量，再检查。缺少证明的解引用报告 CV-PTR-NONNULL，不插入运行时检查。仅传递可空地址无需证明。非空不等于存活。

## 原生表示与责任

Read/Write 目标逐层转换为 C++ const T*/T*，Read 参数按值传地址，Write 为对应指针引用。先确定要解引用的地址，再求值可能修改指针变量的后续操作数。保存/传递地址只需目标声明；原生类型表达式自身仍遵循完整性要求。纯 Carven 可调用签名的参数不要求其类型在此处完整，例如 `struct Node { callback: ptr<fn(Node) -> void> }` 合法，也可通过生成的 C++ 接口导出。

复制、传递、Take 不分配、不引用计数、不释放，外部资源的释放规则由所有者或适配器负责。`T**` 输出参数及缓冲区遍历由 C++ 适配器实现；&p 只按引用传递指针变量，不隐式形成 `T**`。import(cpp)/export(cpp) 保留同样指针和访问规则。

## 存活性检查

静态执行在解引用时验证局部对象和文本字节底层存储的生命周期，包括作用域退出和 Take。普通运行时指针没有一般借用/存活检查，原生地址由提供者保证有效期。
