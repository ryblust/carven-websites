## 执行阶段

程序有编译时静态阶段与生成程序的运行时阶段。`const fn` 声明可在静态阶段执行的能力；常量初始化器、`const { ... }` 和 `const test` 在该阶段运行。`const if` 选择分支、`const for` 展开迭代，剩余语句仍在所属函数体的阶段执行。常量保留编译期执行得到的完整结果，后续使用无需重新运行初始化器。文中把这种保留称为冻结：例如 String 仍是 String，文本会保留下来供程序使用。

## 常量声明

模块 const 只有 Read，没有运行时绑定、源地址或链接身份。private 与裸声明可推断唯一具体类型；export const 必须显式注解，后缀不能代替注解。模块目标须具名，不能 `_` 或元组分解。初始化按依赖完成，支持前向引用；依赖环产生 `CV-CONST-CYCLE`。

```carven
private const radix = 10;
const retry_limit: i32 = 3;
export const protocol_version: u32 = 1;
```

局部 const 是静态名字，按选中实例或展开位置执行一次；未选中 const if 分支与空 const for 不执行。常量本身无需 lambda 捕获，其值须在构造该 lambda 体时可确定；不能跨越未绑定静态参数边界。

## 常量表达式的范围

初始化器和数组长度使用普通类型、访问、作用域与控制流规则。if、match、try 可直接产生常量，所有分支先接受名字、类型、访问和失败检查，执行时只运行选中路径。分支不能选择不同结果类型。

```carven
const compact = true;
const width = if compact { 4usize } else { 8usize };
const table: [i32; if compact { 2usize } else { 4usize }] = [0, 0];
```

完成的常量保留结果类型，包括 `String`、`Vector<T>`、void 和聚合组成。保留的所有者及其字段、元素使用不可变的程序期存储，函数内声明的常量也如此；普通可变复制拥有自己的存储与寿命。

类型形成在所有分支特化前检查。需要局部常量的数组长度、C++ 构造类型查询或独立构造的函数体，只能使用与未绑定静态参数无关且可准入的值；不能直接或通过包装函数读取时钟、输入或等待。可以构造配置或冷 operation 而不执行其宿主工作。需要宿主值同时决定类型时，先在模块 const 完成该观察，再使用冻结结果；局部 const 的宿主观察只在其通常静态位置执行，类型查询不能提前读取它。

知道运行时结果不使普通调用成为常量。整数常量 cast 按模 `2^N` 转换，整数算术回绕与运行时一致；执行到除零或非法移位时编译失败。浮点静态算术使用宿主环境，普通运行时表达式保留目标操作，不额外获得宿主计算的可选常量事实。

## 常量块

`const { ... }` 可在模块或语句块中出现，不带尾分号。`const "prepare table" { ... }` 的标签仅用于诊断，不定义符号。模块块执行一次；函数/lambda/测试中的块按选中实例或展开位置执行。普通运行时条件和循环不选择或重复该块，未调用函数中的块仍是该函数静态阶段的一部分。

块可读模块常量及外围局部常量、静态参数和 const for 索引，不能读取、写入或捕获外围运行时存储。块内局部值按源顺序在静态阶段执行；嵌套块可读外围静态局部值。支持普通可变值、控制流、聚合、文本、const fn 和失败恢复；不执行原生 C++ 实现。

块建立词法作用域，内部寿命在块结束时结束；return 不能离开块，break/continue 只到块内循环。同一函数体的块与局部常量按源顺序执行，不同函数体/模块块之间顺序未定义，导入不建立初始化顺序。输出面向编译器调用者，其他块不能读回。

`?` 可传播到块边界；逸出失败、执行错误或预算超限使编译失败，已完成输出保留。测试内的块可向该测试报告 check/require/fail，其他位置不能用这些测试操作。check 命令也执行块，块不产生运行时测试项。

## `const fn`

一次编译期执行从常量初始化器、const 块或 const test 开始，这个起点称为静态根；这次执行中的调用共享它的预算。准入检查回答“编译器能否执行这些操作”，冻结检查回答“完成后的结果能否保留下来”，两者分开检查。

静态根只能调用已知 const fn，包括局部可调用值绑定选中的 const fn。定义即检查可达签名与操作的执行器能力，未调用也如此；普通分支的已知条件不省略能力检查。无条件退出后的源码仍检查普通语义，但无需执行器能力。递归可用，前提是结果与依赖能完成；能力检查不证明终止。

const 是执行能力，不承诺纯函数或只依赖实参。宿主工作发生在选中的执行阶段；声明不执行，普通调用不把效果移到编译期。const 参数仍要求合格静态源，整个函数在编译期运行也不会把普通参数/let/var 变成静态参数。

```carven
const fn label(count: i32) -> String {
    var result = String {};
    for index in 0..count { result.append_format(f"{index:02}"); }
    return &&result;
}
const name: String = label(3);
const view: str = name;
println(view); // 000102
```

支持标量、单元值、数组、元组、结构体、类、枚举、Vector、文本与字符遍历、借用视图、匹配、Read/Write/Take、局部指针、失败恢复及允许的 SIMD/格式操作。const 类操作保留私有表示权限。原生操作及没有可执行 Carven 体的可调用值不可执行。局部指针在目标退出作用域或 Take 后解引用产生 `CV-CONST-EVALUATION`，重新赋值不复活旧地址身份。非空执行期局部指针不能发布为常量。

Read 实参若含数组、Vector、String 存储，在所有实参求值后观察内容；其他支持值在实参位置保存快照。静态执行直接函数到 view 适配及同类型 view 复制；活元素的现有 view 扩宽依赖目标借用，执行器不支持。空数组无需元素适配。

静态执行也支持允许的[异步](/zh/reference/async/)、[时间](/zh/reference/time/)及[输入输出](/zh/reference/io/)操作，具体宿主能力、等待与取消契约见对应条目。

## 编译期失败契约

throw 创建类型化载荷，? 传播，try/catch 按类型和模式恢复，守卫条件、或模式、嵌套处理和 rethrow 使用普通规则。Take catch 绑定不消耗 rethrow 保留的原始失败。失败载荷仍须可复制，允许拥有文本与聚合。

初始化器或长度中的 `fallible()?` 若成功可完成常量，实际失败逸出在 throw 处诊断并显示调用链。不能因为此次成功省略 ?，也不能对已证明无失败的表达式多写 ?。静态测试不允许逸出失败。执行器错误、预算和断言失败不是可 catch 的类型化失败。

## 准入与冻结

执行能力与结果冻结是不同要求。String 保留拥有类型，不自动变 str；显式 str 上下文或 as_str 才保留文本视图。Vector 保留元素类型、内容和容量；聚合字段不递归改成视图。

常量初始化完成时可保留仍存活的 str、字符视图及数组/Vector 切片，选中内容取得不可变程序期 后备存储；不能借冻结使普通函数局部所有者的悬垂视图逃逸。声明与后备存储没有源级地址身份，原生代码不能依赖不同使用共享地址。

```carven
const letters = String::from_str("aé我").chars;
const table: [i32] = [2, 4, 6];
const middle = table.slice(1, 3);
const count = middle.length();
fn table_view() -> [i32] => table;
```

空切片保留元素类型；索引与半开范围在执行时检查。静态计算中的普通视图仍借用存活的后备存储，复制和链式切片不延长其寿命。运行时的数组/Vector 到切片转换仍遵循借用规则。

## 编译期与运行时算术

整数取负、加减乘、左移按位宽回绕；MIN / -1 得 MIN，余数零。除零及非法移位在必需编译期执行中诊断，在运行时终止。浮点使用执行宿主原生环境，保留有符号零、无穷及 NaN；不同目标/优化/舍入设置不保证相同位模式。

## 与 C++ 常量设施的关系

const fn 由 Carven 执行器检查并执行，不是 C++ constexpr 的关键字替换。原生函数即使声明 constexpr，也不因此进入 Carven 静态执行。保留 String/Vector 与冻结视图遵循 Carven 自己的结果和存储规则。

## 执行预算

| 限制                 | 值      |
| -------------------- | ------- |
| 每棵调用树的执行步数 | 100,000 |
| 嵌套调用深度         | 128     |
| 单个文本值           | 1 MiB   |
| 累计文本构造与复制   | 8 MiB   |
| 单个聚合递归槽位     | 65,536  |
| 聚合嵌套             | 64      |
| 累计槽位构造与复制   | 524,288 |

追加按新增字节计费，查询不复制接收者；预算按工作而非活内存计算。保留数组和构造常量子切片按元素引用计入工作。格式另有嵌套限制。定义违反能力用 `CV-CONST-ADMISSION`，执行错误用 `CV-CONST-EVALUATION`，超限用 `CV-CONST-LIMIT`，断言用 `CV-ASSERT`；失败不回退运行时。
