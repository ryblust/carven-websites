## 常量声明

模块 `const` 定义一个具名、定型的编译期值。private 与裸声明可推断类型；`export const` 必须显式注解类型，字面量后缀不能替代该注解。模块级 `const _` 非法。

```carven
private const radix = 10;
const retries: i32 = 3;
export const protocol: u32 = 1;
```

按依赖完成初始化，允许前向引用，必需事实成环产生 `CV-CONST-CYCLE`。每次使用同一归一化值。常量只有 Read，不产生运行时绑定、源地址或链接身份。冻结切片可以有静态 backing，但声明本身仍没有地址身份。

局部 `const` 是静态词法名字。在运行时函数体中，它为每个选中的实例或展开位置执行一次；未选中的 `const if` 分支或空 `const for` 不执行它。lambda 只有在构造自身函数体时能确定常量值，才可以不捕获而直接使用可见常量；未绑定的外围静态参数不能跨越该边界。

## 常量表达式的范围

支持字面量、数值枚举 case、已完成常量、括号、允许的 cast 与纯一元/二元操作、常量文本查询、全常量载荷构造、支持的插值和 `String` 操作，以及以常量实参调用显式 `const fn`。固定数组、结构体、索引和字段可在允许的聚合子集中产生常量。数组和符合条件的枚举支持相等，结构体不支持。常量初始化器也可创建和查询冻结切片。可失败调用必须使用 `?`；失败逃出静态根时编译失败。

普通 `fn` 调用和直接控制流表达式不是常量表达式；必需常量调用普通函数会报告 `CV-CONST-ADMISSION`。需要分支或循环时放入 `const fn` 或常量块。知道运行时结果并不让表达式成为常量；例如带普通调用的 `(source() == 1) && false` 仍不符合常量表达式要求。

整数字面量按所选类型检查范围。整数取负、加、减、乘和左移按类型宽度回绕，与运行时完全一致；若 `max: i32 = 2147483647`，`const wrapped = max + 1;` 得到 `-2147483648`。除零和非法移位数在编译期执行到时诊断。整数 cast 按目标宽度模转换。必需常量执行支持 `f32`/`f64` 的取负、算术、比较和允许的数值 cast。`const x = 1.0 + 2.0;` 求值得到 `3.0`。普通运行时浮点算术和排序仍保留原生执行，不通过宿主计算额外推导常量事实。

## 常量块

`const { ... }` 可出现在模块顶层或语句块内，不带尾分号。可选字符串为诊断加标签，例如 `const "prepare table" { ... }`；标签不是符号，也不要求唯一。模块级块执行一次。函数体中的块为每个选中的实例或展开位置执行一次，未选中的 `const if` 分支和空 `const for` 不执行它。运行时控制不选择它：未调用函数、运行时分支或运行时循环内的块为该函数体执行一次，运行时不会重复。块支持可变局部值、控制流、文本、聚合、`const fn` 与失败恢复；外部 C++ 构造和调用仍不在执行器子集内。

块有自己的词法作用域。它可以使用模块常量和外围静态绑定：局部常量、`const` 参数与 `const for` 索引，遵循普通查找与遮蔽规则。外围运行时参数和局部值不能读取、写入或捕获。块内所有局部值都按源顺序在静态阶段执行；局部 `const` 是不可变局部值，普通与 `const` 控制按相同执行顺序运行。嵌套块可以读取外围静态局部值，并保留自己的诊断标签。同样规则适用于 `const test`，不改变 `const fn` 的特化。

块不是 callable：`return` 不能离开它，break/continue 只作用于块内循环。同一函数体中的块与局部常量按源顺序执行；不同函数体和模块块之间的顺序未定义，导入不建立块的初始化顺序。声明和寿命在块内结束。输出与诊断面向编译器调用者，其他块不能读回输出。

`?` 可传播到块边界。逃逸失败、执行错误或预算耗尽使编译失败；已完成输出保留。测试体内的块在编译时把 check/require/fail 报告给该测试；其他位置拒绝这些操作。块的执行不依赖测试产物选项，`check` 也执行它们，不创建运行时测试项。

## `const fn`

`const fn` 声明一个具名 Carven 函数可以在必需常量上下文中被调用：局部与模块常量初始化器、数组长度、常量块和 `const test`。必需上下文只调用这类函数。仅声明不会执行它；运行时调用仍是普通调用，即使参数全部已知。入口和 import(cpp) 声明不能是 `const fn`。

```carven
const fn label(count: i32) -> String {
    var result = String {};

    for index in 0..count {
        result.append_format(f"{index:02}");
    }

    return result;
}

const name = label(3); // str: 000102
```

每个 `const fn` 在定义处检查执行器能力，而不是等到第一次调用。签名和语义上可达的操作都必须受支持；每个可达调用，包括通过局部 callable 绑定的调用，都必须选中已知的 `const fn`。否则即使没有任何调用，定义处也会报告 `CV-CONST-ADMISSION`：

```carven
fn double(value: i32) -> i32 => value * 2;

// 编译错误：CV-CONST-ADMISSION，double 不是 const fn。
const fn quadruple(value: i32) -> i32 => double(double(value));
```

无条件 return 之后的操作仍接受普通语义检查，但不需要执行器能力。已知条件不会从能力检查中排除普通源码分支；只由调用实参选择的路径仍接受检查。签名和函数体能在没有构造依赖环的情况下完成时允许递归，能力检查不证明终止。

签名遵循普通规则，包括 Read、Write 和 Take 参数。void 结果不能初始化常量；其他结果必须能进入使用它的常量边界。结果推断沿用普通函数规则。

支持标量算术、比较、逻辑运算与 cast；局部初始化、赋值和 Take；if/match/while、C 风格 for、整数区间、数组与切片循环；return/break/continue；直接 `const fn` 调用，以及通过具名 `const fn` 的局部绑定进行的间接调用。match 支持内建与枚举主体、字面量/整数区间/枚举 case/绑定/通配/或模式以及 guard。目标存活时可以创建并解引用局部指针，Write 参数会更新调用方存储。

```carven
const fn total(values: [i32]) -> i32 {
    var sum = 0;
    for value in values {
        sum += value;
    }
    return sum;
}

const fn bump(&value: i32) {
    value += 1;
}

const fn run() -> i32 {
    let values = [1, 2, 3, 4];
    var result = total(values.as_slice().slice(1, 3));
    bump(&result);
    let sum = total;
    return sum(values.as_slice()) + result;
}

const answer = run(); // 16
```

`String` 支持构造、复制、as_str、len/is_empty、append/append_format、push/clear、字节视图与循环、插值和打印。插值支持整数、`bool`、`char`、文本（包括已知 C 字符串）的默认格式，以及整数 `b/B/o/d/x/X`、十进制宽度与零填充。浮点格式支持 `a/A/e/E/f/F/g/G`、填充、对齐、符号、alternate form、零填充、宽度与精度，不支持依赖区域设置的 `L`。动态宽度和精度先求值，必须为非负整数。数组支持构造、索引、元素赋值、相等、复制、Read/Write 迭代、Take、参数与结果。切片在存活 backing 上支持索引、子切片与循环。结构体支持构造、字段访问/赋值、复制、Take、参数与结果，不支持相等。

枚举支持 case 构造、载荷匹配、相等、复制、Take 和参数/结果。字段、元素和载荷递归遵循同样的执行类型规则；发布完成的常量还要求每个组成部分都能冻结。不把 `String` 字段或元素冻结成 `str`。空数组须有元素上下文。保持名义身份、长度和每个成员类型。C 字符串支持常量初始化、调用、局部复制、赋值和 Take；冻结保留其字节与指针类型。

含数组或 `String` 存储的 Read 实参在所有实参求值后观察内容；其他支持的值在实参位置保存。字段和索引投影按选中值的类型规则处理。

## 编译期失败契约

`const fn` 使用普通失败契约规则：throw 创建带类型的载荷，`?` 传播，try/catch 按类型与载荷匹配。guard、或模式、嵌套恢复和 rethrow 都参与相同的执行流程。载荷支持拥有文本和可执行的聚合值；取走 catch 绑定不会消耗 rethrow 保留的原始失败。

在常量初始化或数组长度中，`fallible()?` 将失败交给求值入口：实际成功可形成常量，实际逃逸则在 throw 位置诊断并附调用上下文。即使本次成功，也不能省略 fallible 调用所需的 `?`；无失败表达式上的多余 `?` 仍会被拒绝。推断契约最终仍由普通失败求解器检查。`const test` 保留静态规则：不能有未处理失败逃逸。求值器错误、预算耗尽和失败断言不能用 catch 恢复。

## 准入与冻结

原生操作、没有可执行 Carven 函数体的调用、字符迭代、未检查借用文本构造与类的值/操作仍不在静态执行范围内。普通类型、访问、所有权与寿命检查始终适用。目标离开作用域或被 Take 后解引用局部指针，报告 `CV-CONST-EVALUATION`；非空局部指针不能发布为常量。执行与冻结是不同要求。

`char::from_u32_unchecked` 可用于常量初始化和 `const fn`。执行到的参数必须是 Unicode 标量；代理项或超过 U+10FFFF 的值报告 `CV-CONST-EVALUATION`。原生执行保留调用者的前置条件。受检查的 [UTF 标量、编解码与验证函数](/zh/reference/utf/#编译期使用)和 [SIMD lane 操作](/zh/reference/simd/)也可在编译时执行。借用 UTF 文本构造和类验证器仍在运行时执行。

`String` 在计算中保持拥有与 Take 语义。只有整个常量初始化完成时，拥有文本结果才冻结为 `str`；`const name: String = label(3);` 非法。切片在执行期间借用存活的 backing；完成的常量根会先冻结选中的元素，再释放 backing。

## 编译期与运行时的算术

整数算术在编译期和运行时相同。取负、加、减、乘和左移按类型宽度回绕；有符号 `MIN / -1` 得到 `MIN`。除以零或对零取余、负数或超出宽度的移位数，在必需执行到达时诊断（`CV-CONST-DIVIDE-BY-ZERO`、`CV-CONST-SHIFT-RANGE`），在运行时终止。

```carven
const fn next(value: u8) -> u8 => value + 1;

const wrapped = next(255);

const test "wrapping matches runtime" {
    check(wrapped == 0);
}

println(next(255)); // 0
```

短路与控制流决定实际执行哪些操作。未执行的除零不会触发求值错误，但 `const fn` 中可达的不支持原生调用仍会在定义处被拒绝。

浮点执行使用编译器宿主的原生 float/double 环境。有符号零、无穷和 NaN 都是可保留的值；浮点除零遵循原生浮点规则，不使用整数除零诊断。冻结结果会在生成的 C++ 中重建，但不承诺与不同目标配置、舍入环境或优化选项下的运行时表达式结果逐位一致。

## 与 C++ 常量设施的关系

这些形式不能仅按关键字替换：

| Carven 规则                                                   | C++20 对照                                                                                        |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `const fn` 声明一种在定义处检查的能力；运行时调用仍是普通调用 | `constexpr` 函数也可以在编译期或运行时调用，但准入规则不同                                        |
| 常量初始化完成时，`String` 结果冻结为 `str`                   | `constexpr` string 可以参与构造；保留文本结果需要满足常量表达式与存储规则，不自动变成 string_view |
| `const test` 在语义分析时执行支持子集的测试体                 | `static_assert` 检查常量条件；不能直接替代整个测试体                                              |
| 原生 C++ 调用不能进入 Carven 的必需常量执行                   | C++ 函数声明为 `constexpr` 不会改变这一边界                                                       |

[编译期教程](/zh/learn/constants/)提供同一文本构造的完整 C++20 对照。冻结是结果表示规则，不承诺每个运行时 `const fn` 调用都消除分配。

## 执行预算

| 限制                      | 数值    |
| ------------------------- | ------- |
| 每个调用树执行步数        | 100,000 |
| 嵌套调用深度              | 128     |
| 单个文本值                | 1 MiB   |
| 累计文本构造、复制和输出  | 8 MiB   |
| 单聚合全部嵌套字段/元素槽 | 65,536  |
| 聚合嵌套层数              | 64      |
| 累计槽位构造和复制        | 524,288 |

追加计新增字节，查询不复制接收者。预算衡量工作量，不是存活内存。直接聚合初始化同样受大小、层数和工作预算约束，格式说明另有嵌套限制。

必需表达式或 `const fn` 能力检查遇到不支持的操作为 `CV-CONST-ADMISSION`，执行错误为 `CV-CONST-EVALUATION`，断言失败为 `CV-ASSERT`，预算超限为 `CV-CONST-LIMIT`；类型、算术和依赖诊断仍适用。失败不回退运行时。
