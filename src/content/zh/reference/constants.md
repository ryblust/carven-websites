## 常量声明

模块 const 定义一个具名、定型的编译期值。private 与裸声明可推断类型；export const 必须显式注解类型，字面量后缀不能替代该注解。模块级 `const _` 非法。

```carven
private const radix = 10;
const retries: i32 = 3;
export const protocol: u32 = 1;
```

按依赖完成初始化，允许前向引用，必需事实成环产生 `CV-CONST-CYCLE`。每次使用同一归一化值。常量只有 Read，不产生运行时绑定、源地址或链接身份。冻结切片可以有静态 backing，但声明本身仍没有地址身份。

局部 const 是编译期词法名字，lambda 可直接使用，不需要捕获。

## 常量表达式的范围

支持字面量、数值枚举 case、已完成常量、括号、允许的 cast、纯一元和二元操作、常量文本查询、全常量载荷构造、支持的插值和 String 操作、常量参数的直接 const fn 调用。固定数组、结构体、索引、字段和逐成员相等可在允许的聚合子集中产生常量。常量初始化器也可创建和查询冻结切片。

普通函数调用和直接控制流表达式不是常量表达式。需要分支或循环时放入 const fn。知道运行时结果并不让表达式成为常量；例如带普通调用的 `(source() == 1) && false` 仍不符合常量表达式要求。

整数常量算术检查溢出、除零与移位范围。整数 cast 按目标宽度模转换。必需常量执行支持 f32/f64 的取负、算术、比较和允许的数值 cast。`const x = 1.0 + 2.0;` 求值得到 `3.0`。普通运行时浮点算术和排序仍保留原生执行，不通过宿主计算额外推导常量事实。

## 常量块

`const { ... }` 可出现在模块顶层或语句块内，不带尾分号。块在语义分析时恰好执行一次，包括未调用函数、未选中运行时分支和循环内的块；不生成运行时代码。块使用常量执行的类型与操作规则，可包含可变局部值、控制流、文本、聚合、const fn 调用与失败恢复。

每个块都有独立词法作用域、存储和预算。它可读取可见常量，不能读取外围执行帧的参数或局部运行时值。结果为 void；`return;` 或 void 返回操作数结束当前块，循环转移只能指向块内循环。嵌套常量块也是独立求值根。

跨块执行顺序未定义；需要顺序的操作写在同一块中。块内声明与对象寿命在块内结束。输出与诊断面向编译器调用者，其他块不能读回输出。

`?` 可将失败传播到块边界，逃逸失败、执行错误或预算耗尽使编译失败；已完成输出保留。常量块不创建测试上下文，check/require/fail 需要活动的 const test。块的执行不依赖测试产物选项，`check` 也执行它们。

## const fn

const fn 是可以被必需常量上下文执行的命名函数。仅声明它不会执行；普通运行时调用仍是运行时调用，即使参数都是字面量。入口和 import(cpp) 不能是 const fn。

```carven
const fn label(count: i32) -> String {
    var result = String {};

    for index in 0..count {
        result.append_format(f"{index:02}");
    }

    return result;
}

const name = label(3); // str: 000102
```

参数使用 Read 或 Take，类型支持整数、f32/f64、bool、char、str、String、整数区间和允许的固定数组/结构体/枚举。结果支持这些类型或 void，void 不能初始化常量。结果推断沿用普通函数规则。

允许局部初始化、赋值、Take、标量运算、if/match/while、C 风格 for、整数范围和数组范围、return/break/continue、直接 const fn 调用和可完成依赖的递归。match 支持内建与枚举主体、字面量/整数区间/枚举 case/绑定/通配/或模式以及 guard。

允许 String 构造、复制、as_str、len/is_empty、append/append_format、push/clear、插值和打印。插值支持整数、bool、char、文本的默认格式，以及整数 `b/B/o/d/x/X` 表示、十进制宽度和零填充。f32/f64 支持默认格式与 `a/A/e/E/f/F/g/G`，以及填充、对齐、符号、宽度和精度，遵循原生标准库格式规则。动态宽度和精度先求值，并接受非负整数；编译期格式化不使用依赖区域设置的 `L`。数组支持构造、索引、元素赋值、相等、复制、Read/Write 迭代、整绑定 Take 和参数/结果。结构体支持构造、字段访问/赋值、相等、复制、整绑定 Take 和参数/结果。

枚举支持 case 构造、载荷匹配、相等、复制、Take 和参数/结果。聚合内部支持数值类型、整数区间、bool、char、str、String 和递归数组/结构体/枚举；不把 String 字段或元素冻结成 str。空数组须有元素上下文。保持名义身份、长度和每个成员类型。

Read 数组及含数组结构体在所有实参求值后观察内容；标量与不含数组的支持结构体在实参位置保存值。Read String 也在所有实参或孔完成后读内容。字段和索引投影按选中值的类型规则处理。

## 编译期失败契约

const fn 使用普通失败契约规则：throw 创建带类型的载荷，`?` 传播，try/catch 按类型与载荷匹配。guard、或模式、嵌套恢复和 rethrow 都参与相同的执行流程。载荷支持拥有文本和可执行的聚合值；取走 catch 绑定不会消耗 rethrow 保留的原始失败。

在常量初始化或数组长度中，`fallible()?` 将失败交给求值入口：实际成功可形成常量，实际逃逸则在 throw 位置诊断并附调用上下文。即使本次成功，也不能省略 fallible 调用所需的 `?`；无失败表达式上的多余 `?` 仍会被拒绝。推断契约最终仍由普通失败求解器检查。const test 保留静态规则：不能有未处理失败逃逸。求值器错误、预算耗尽和失败断言不能用 catch 恢复。

## 准入与冻结

所有定义都检查，包括未调用函数和不活动分支。const fn 不支持原生操作、Write 参数/实参、指针、切片、callable、间接调用、文本 bytes/chars 迭代和 unchecked 文本构造。局部可变存储与数组 Write 迭代仍可用。一个值能参与执行，与它能否保留在生成的常量中，是两个不同的要求。

String 在计算中保持拥有与 Take 语义。只有整个常量初始化完成时，拥有文本结果才冻结为 str；`const name: String = label(3);` 非法。数组结果可在此边界变成冻结切片；const fn 内部不能操作切片。

## 编译期与运行时的算术

必需常量执行检查整数溢出、除零和非法移位。普通运行时调用同一个 const fn 时，整数算术仍遵循运行时规则，包括加、减、乘的模回绕。函数的 const 修饰不把所有调用都改成受检算术。

短路与控制流决定实际执行哪些操作；定义准入仍检查所有分支。未执行的除零不会触发求值错误，不支持的原生调用则不能靠不活动分支隐藏。

浮点执行使用编译器宿主的原生 float/double 环境。有符号零、无穷和 NaN 都是可保留的值；浮点除零遵循原生浮点规则，不使用整数除零诊断。冻结结果会在生成的 C++ 中重建，但不承诺与不同目标配置、舍入环境或优化选项下的运行时表达式结果逐位一致。

## 与 C++ 常量设施的关系

这些形式不能仅按关键字替换：

| Carven 规则                                               | C++20 对照                                                                                      |
| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| const fn 声明允许必需常量执行；普通调用仍按运行时规则执行 | constexpr 函数也可以在编译期或运行时调用，但准入规则不同                                        |
| 常量初始化完成时，String 结果冻结为 str                   | constexpr string 可以参与构造；保留文本结果需要满足常量表达式与存储规则，不自动变成 string_view |
| const test 在语义分析时执行支持子集的测试体               | static_assert 检查常量条件；不能直接替代整个测试体                                              |
| 原生 C++ 调用不能进入 Carven 的必需常量执行               | C++ 函数声明为 constexpr 不会改变这一边界                                                       |

[编译期教程](/zh/learn/constants/)提供同一文本构造的完整 C++20 对照。冻结是结果表示规则，不承诺每个运行时 const fn 调用都消除分配。

## 执行预算

| 限制                      | 数值    |
| ------------------------- | ------- |
| 每个调用树执行步数        | 100,000 |
| 嵌套调用深度              | 128     |
| 单个文本值                | 1 MiB   |
| 累计文本构造、复制和输出  | 8 MiB   |
| 单聚合全部嵌套字段/元素槽 | 65,536  |
| 聚合嵌套层数              | 64      |
| 累计槽位构造和复制        | 524,288 |

追加计新增字节，查询不复制接收者。预算衡量工作量，不是存活内存。直接聚合初始化同样受大小、层数和工作预算约束，格式说明另有嵌套限制。

定义准入错误为 `CV-CONST-ADMISSION`，执行错误为 `CV-CONST-EVALUATION`，预算超限为 `CV-CONST-LIMIT`；类型、算术和依赖诊断仍适用。失败不回退运行时。
