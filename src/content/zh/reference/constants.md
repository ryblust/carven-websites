用 `carven check main.cv` 执行各个完整示例中需要编译期求值的部分。包含顶层运行时语句的示例也可以用 `carven run main.cv` 运行。

## 执行阶段

程序有编译时静态阶段与生成程序的运行时阶段。`const fn` 声明可在静态阶段执行的能力；常量初始化器、`const { ... }` 和 `const test` 在该阶段运行。`const if` 选择分支、`const for` 展开迭代，剩余语句仍在所属函数体的阶段执行。

常量保留编译期执行得到的完整结果，后续使用无需重新运行初始化器。文中把这种保留称为冻结：例如 String 仍是 String，其字节会保留下来供程序使用。

## 常量声明

顶层 `const` 为一个带类型的常量建立模块级名称。项目内部共享的常量无需可见性修饰符，仅供本模块使用的常量标记为 `private`。下面的 `export` 声明专门演示供其他 Craft 使用的公共 API：

```carven
private const radix = 10;
const retry_limit: i32 = 3;
export const protocol_version: u32 = 1;
```

`private` 常量和未标注可见性的常量可以推断唯一的具体类型，也可显式注解。`export const` 必须显式注明类型，初始化器中的后缀不能代替注解；省略注解报告 `CV-CONST-EXPORTED-TYPE`。注解为初始化器提供期望类型，使用普通兼容规则。模块目标必须是具名标识符，不能使用 `_` 或元组目标。

模块常量按声明依赖完成初始化，允许前向引用。每次使用都引用同一个规范化后的常量值；依赖环产生 `CV-CONST-CYCLE`。模块常量只有 Read 访问，不会创建运行时变量，也没有可在源语言中取得的地址或链接符号。冻结视图的底层存储具有静态生命周期，但不意味着可以在源语言中取得常量声明的固定地址。

## 常量表达式的范围

`const` 初始化器和数组长度在语义分析期间求值，遵循普通表达式的类型、访问、作用域和控制流规则。`if`、`match`、`try` 可直接产生值：

```carven
const compact = true;
const width = if compact { 4usize } else { 8usize };
const table: [i32; if compact { 2usize } else { 4usize }] = [0, 0];
```

每个分支都接受名字、类型、访问和失败检查，结果类型必须兼容。执行时只运行选中路径。分支局部绑定和循环沿用普通作用域与生命周期。`try` 可在本次编译期求值结束前处理失败并恢复执行。数组长度必须是非负整数；常量初始化器的结果必须能够冻结。

冻结保留结果类型，包括具有独立存储的 `String`、`Vector<T>`、`void` 和聚合中的各个组成部分。局部与模块常量只存在于静态阶段，后续使用选择规范值，不创建运行时绑定或 lambda 捕获。保留的所有者及其字段、元素使用在程序整个运行期间有效的不可变存储，函数内声明的常量也如此。普通可变副本拥有自己的存储与生命周期。

函数体内的局部 `const` 在静态阶段的对应位置执行，每个选中实例或展开位置执行一次。未选中的 `const if` 分支与空 `const for` 不执行其中的初始化器。

所有分支中的类型都在特化前接受检查。需要局部常量的数组长度、C++ 构造类型查询或独立构造的函数体，只能使用不依赖尚未绑定的静态参数、且编译器支持求值的值。这些依赖查询不能直接或通过包装函数读取时钟、输入或等待；可以构造配置或冷操作而不执行其宿主工作。

需要用编译器宿主上的输入、时钟等操作结果决定类型时，先在模块 `const` 中读取并保留结果，再用这个常量确定类型。局部 `const` 中的这些宿主操作仍在通常的编译期求值位置执行，类型查询不能提前读取它。

普通条件即使值已知，也遵循[控制流分析规则](/zh/reference/control/#顺序与不活动代码)。[`const if`](/zh/reference/functions/#静态控制)显式选择特化。

整数计算和转换遵循[数值规则](/zh/reference/types/#算术与终止)。必需静态执行实际到达除零或非法移位时，产生编译诊断。浮点计算使用编译器宿主的浮点环境。即使编译器能确定运行时结果，普通函数调用也不会因此获得编译期执行能力；编译期求值中的调用目标必须有 `const fn` 能力。

## 常量块

`const { ... }` 在编译期执行语句块，不带尾分号。`const` 后可以有诊断标签，例如 `const "prepare table" { ... }`；标签不定义符号，也不要求唯一。常量块可以位于模块或接受语句的块中：

```carven
const {
    var total = 0;
    for index in 0..10 {
        total += index;
    }
    println(total);
}

fn resize(const width: i32) {
    const for lane in 0..3 {
        const {
            assert(width > 0);
            println(f"lane {lane} of width {width}");
        }
    }
}
```

模块层级的块执行一次。函数、lambda 或测试体中的块属于该体的静态阶段，每个选中实例或展开位置执行一次。未选中的 `const if` 分支和空 `const for` 不执行其中的块。普通运行时条件或循环不选择、不重复常量块；不带静态参数的函数即使未调用，其块也会执行一次。

块支持静态阶段的可变局部值、控制流、聚合、文本、`const fn` 调用与失败恢复，普通类型、所有权和生命周期检查仍然适用。Carven 执行器仅通过宿主显式提供的类型化绑定执行原生操作，不编译或加载 C++ 提供者函数体。原生默认构造仍不受支持。

块建立自己的词法作用域，可按普通查找与遮蔽规则读取模块常量及外围静态绑定，包括局部常量、静态参数和 `const for` 索引。外围运行时参数和局部变量此时不存在，不能读取、写入或捕获。块内局部值按源顺序在静态阶段执行，生命周期在块内结束。局部 `const` 是该阶段的不可变局部值；`const if` 和 `const for` 按普通 `if`、`for` 执行，允许对局部值进行普通 Read、Write 遍历。嵌套块可读取外围静态局部值，并保留自己的诊断标签。`const test` 也使用这些块内规则。

`return` 不能离开常量块，`break`、`continue` 只作用于块内循环。同一函数体的块与局部常量按源顺序执行；不同函数体及模块块之间顺序未定义。导入不建立块之间的初始化顺序。输出面向编译器调用者，其他块不能读回。

`?` 可把失败传播到块的执行边界。逸出失败、执行错误或预算超限使编译失败，已完成输出仍保留。

`check`、`require`、`fail` 需要测试上下文：测试内的块向该测试报告，其他位置拒绝这些操作。无论是否生成测试产物，常量块都会执行，包括在 `carven check` 期间；它不生成运行时代码或测试项。

## `const fn`

一次编译期求值从常量初始化器、常量块或 `const test` 等入口开始。这次求值中的调用共享该入口的执行预算。编译器先检查是否支持所用的操作，求值完成后再检查结果能否冻结并保留下来。

编译期求值可以调用具名 `const fn`，以及满足静态执行要求的 lambda，适用于局部和模块常量初始化器、数组长度、常量块和静态测试。实参遵循类型与访问规则，每个函数体仍接受普通类型、失败、所有权和生命周期检查。普通调用仍在运行时执行，即使实参全都已知。

`const fn` 可以修改局部状态，也可在编译器宿主上执行受支持的输入、打印、时钟查询和等待操作。编译期求值使用编译器宿主的资源，普通运行时调用使用程序的资源。函数声明本身不执行代码。

`const name: T` 参数在每种执行模式中都要求合格的静态输入。执行器知道普通参数、`let` 或 `var` 的值，并不会赋予它们静态参数资格。整个函数在编译期执行，也不改变这一调用契约。

每个 `const fn` 定义都检查语义可达操作的执行能力。可达的具名源调用必须选中已知 `const fn`；已知 lambda 的签名和函数体按同一规则递归检查。未知可调用参数不能证明静态能力。不支持或不能确定的调用在定义处产生 `CV-CONST-ADMISSION`。无条件退出后的源码仍接受普通语义检查，但不要求执行器能力；由普通实参选择的分支仍参与定义检查。

类型和失败集合实参具体后，编译期求值可以调用参数化 `const fn`。编译器在执行前完成契约推断的传递声明依赖，未完成的失败集合不会被当成空集。泛型定义中的局部 `const` 初始化器不能要求尚未确定的泛型环境。外围 `const fn` 仍可在实参具体后执行普通泛型调用。

执行期间检查预算和动态错误，结束时检查结果能否冻结。同一次编译期求值中的调用共享预算。后续失败不会撤销已经完成的宿主操作，例如已读入的输入或已打印的输出。预算限制步骤和构造工作，不限制输入或等待的实际用时。

冷输入或时间操作在构造时保留实参，等待或启动后才执行读取或等待。冷操作属于局部执行状态，不能冻结为模块常量。可用宿主操作及其失败契约见[异步](/zh/reference/async/)、[时间](/zh/reference/time/)和[输入输出](/zh/reference/io/)。

```carven run
const fn label(count: i32) -> String {
    var result = String {};
    for index in 0..count {
        result.append_format(f"{index:02}");
    }
    return result;
}

const name: String = label(3);
const view: str = name;
println(view); // 000102
```

### 支持的操作

以下操作可在编译期执行，仍须满足普通类型、访问、失败和生命周期规则：

| 值或控制形式                 | 支持的工作                                                                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 标量与单元值                 | 算术、比较、逻辑、转换，以及参数、结果与聚合中的 `void` 值                                                                         |
| 控制流                       | `if`、`match`、`while`、C 风格与遍历循环、`return`、`break`、`continue`；执行预算内的递归                                          |
| 结构体、类、元组、枚举与数组 | 构造、字段或元素访问、允许的修改、复制、完整所有者 Take、传参与返回；类型支持时可比较相等                                          |
| `Vector<T>`                  | 字面量与空构造、从切片复制、索引、遍历、完整所有者 Take、切片、`push`、`append`、`remove`、`clear`、容量构造、查询与预留           |
| 文本                         | 具有独立存储的文本构造、`as_str`、字节和字符视图、字节索引与字节/字符遍历、`append`、`append_format`、`push`、`clear` 和支持的插值 |
| 切片                         | 查询、索引、子切片、遍历，以及对存活数组或 Vector 底层存储的借用                                                                   |
| SIMD                         | [SIMD 执行契约](/zh/reference/simd/)允许的操作                                                                                     |
| 调用                         | 已知 `const fn`、具名函数的局部绑定、满足静态要求的 lambda，以及允许的内建操作                                                     |

构造按源码顺序执行初始化器，空数组字面量需要期望元素类型，嵌套字段、元素和枚举载荷也须支持执行。类操作保留私有表示权限并要求 `const fn`。已有不透明原生值可以传参、返回或包装而不调用原生操作；实际到达的原生调用、成员访问和转换需要宿主显式绑定，C++ `constexpr` 本身不提供这种绑定。不透明原生值不能冻结为常量。

含数组、Vector 或 String 存储的 Read 实参在所有实参求值后观察内容；其他支持值在各自实参位置保存快照。插值占位符也遵循这一顺序：所有占位符求值完成后，再读取 String 的内容，借用视图则持续保护底层存储。见 [Read 值与别名](/zh/reference/ownership/#read-值与别名)和[格式化](/zh/reference/formatting/)。

`char::from_u32_unchecked` 可在这里执行，但操作数必须是 Unicode 标量。执行到代理项或大于 U+10FFFF 的值时，产生 `CV-CONST-EVALUATION`。

### 指针与可调用视图

支持局部取地址、Read 与 Write 调用，以及对存活局部目标的解引用。执行器跨调用与作用域跟踪局部对象的生命周期。目标作用域结束或发生 Take 后，解引用产生 `CV-CONST-EVALUATION`；向已 Take 所有者重新赋值不会复活旧地址。对存活所有者赋值则保留身份。非空局部指针不能冻结为常量结果。

擦除指针的静态格式化产生 `const@nonnull` 或 `const@null`，这些字符串可作为普通文本冻结。非空擦除指针本身，包括擦除后的 C 字符串指针，只能作为局部执行值。

静态与解释执行支持闭包所有者、值和 Write 捕获、函数及闭包可调用视图，以及视图失败集合扩大。闭包复制保留值快照和 Write 别名；扩大后的视图借用源视图存储并观察后续重绑定。数组逐元素适配。调用在实参求值前选定闭包对象，每次捕获使用读取其当前捕获值或 Write 目标。闭包和视图只能留在本次执行内，不能冻结；调用结果按普通常量规则保留。

标为 `const fn` 的文件、进程和编译操作也通过编译器宿主执行，观察其工作目录和环境，并在选定阶段产生效果。原生句柄及中间结果只在执行内存活，不能冻结为常量。允许宿主效果的分析会将其记为不可缓存；类型依赖查询拒绝宿主观察。

## 编译期失败契约

`throw` 创建类型化载荷，`?` 传播失败，`try`/`catch` 按类型和载荷模式恢复。守卫条件、或模式、嵌套处理和 `rethrow` 遵循普通调用与控制流规则。catch 绑定与原始失败遵循[普通载荷访问和生命周期规则](/zh/reference/failures/#rethrow-与生命周期)。载荷可包含具有独立存储的文本与支持的聚合，仍须满足普通可复制要求。

初始化器或数组长度中的 `fallible()?` 若成功，可以完成常量；实际失败逸出时，在 throw 位置报告诊断和调用路径。可失败调用即使实际成功也须标记传播或处理；已证明无失败的表达式不能使用 `?`。静态测试不允许逸出类型化失败。执行器错误、预算耗尽和测试断言失败不能作为类型化失败捕获。

## 常量结果与底层存储

冻结会保留名义类型的身份、字段类型、数组长度、元组元素数量与嵌套结构，以及 String 和 Vector 各自拥有的存储。完成的 Vector 保留内容及容量。复制保留的所有者时，按普通所有权规则创建独立存储。

常量初始化器可在底层存储仍存活时保留借用的 `str` 或字符视图。完成的视图保留类型，所选 UTF-8 内容使用在程序整个运行期间有效的不可变存储：

```carven
const letters = String::from_str("aé我").chars;
```

普通借用视图遵循源的生命周期；函数普通局部所有者的视图不能逃逸该函数。冻结要求初始化器结束时底层存储仍然存活。

通过显式注解或 `slice()`，常量初始化器可以把完成的数组或 Vector 保留为 `[T]`：

```carven
const table: [i32] = [2, 4, 6];
const middle = table.slice(1, 3);
const count = middle.length();
fn table_view() -> [i32] => table;
```

这些元素的底层存储具有静态生命周期，视图可以复制、保存和返回，不受常量声明所在作用域限制。声明及其底层存储没有源级地址身份，原生代码不能依赖不同使用点或产物共享地址。空切片保留元素类型；索引和半开子范围在静态执行时检查边界。

保留为切片时，每个元素仍须能执行并按原类型冻结：`[Entry; N]` 可形成 `[Entry]`，`[[i32; 2]; N]` 可形成 `[[i32; 2]]`。字段保持声明类型，不会递归地将拥有自身存储的字段或嵌套数组改成视图。切片不支持相等比较。

静态函数调用返回的数组或 Vector 也可在这个初始化边界保留为切片。求值期间，切片参数、局部切片、索引和子切片仍借用存活存储；复制和链式切片不延长生命周期。初始化器完成时，再把选中的元素冻结为在程序整个运行期间有效的不可变存储。普通运行时数组或 Vector 转为切片时仍借用原所有者。

保留数组或构造常量子切片时，元素引用数量计入[执行预算](#执行预算)。

## 执行预算

同一次编译期求值中的调用共享下列限制：

| 限制                 | 值        |
| -------------------- | --------- |
| 执行步数             | 1,000,000 |
| 嵌套调用深度         | 128       |
| 单个文本值           | 1 MiB     |
| 累计文本构造与复制   | 8 MiB     |
| 单个聚合中的嵌套槽位 | 65,536    |
| 聚合嵌套层数         | 64        |
| 累计槽位构造与复制   | 524,288   |

槽位包括序列或元组元素、结构体字段和枚举载荷。追加按新增字节计费，查询不复制接收者。保留数组和构造常量子切片按元素引用计入工作。预算按工作计算，格式说明另有嵌套限制。

超限产生 `CV-CONST-LIMIT`，执行错误使用 `CV-CONST-EVALUATION`，定义使用了编译器不支持的操作时使用 `CV-CONST-ADMISSION`。必需静态计算必须在预算内完成，普通类型、算术和依赖诊断仍然适用。
