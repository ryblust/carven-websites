## 插值表达式

`f"..."` 返回独立拥有的 String，即使为空或没有插值字段。插值字段可有 `:` 格式说明，遵循对应 `std::format` 对齐、宽度、精度和类型规则。

```carven
fn main() {
    let id = 42;
    println(f"ID: {id:08x}");
    println(f"{{value}} = {id}");
}
```

动态宽度和精度用嵌套插值字段，例如 `f"{value:{width}.{precision}f}"`。运行时不属于内建优化子集的格式合法性和 formatter 可用性由 C++ 检查。聚合、枚举、callable 没有 Carven 自定义格式化协议；使用其原生表示和对应 formatter。

## 求值和观察时机

所有插值字段，包括动态格式参数，按源码顺序求值一次，然后开始格式化。插值字段是 Read 访问，不能直接写实参标记 `&` 或 `&&`；嵌套调用仍按自己的参数契约。

标量 Read 保存求值时的值；String Read 保留对原对象的别名，在所有插值字段求值完成后读取内容。文本视图在求值与格式化期间保持对底层存储的借用。结果拥有独立内容。

一个插值字段失败会跳过后续插值字段和格式化，保留已完成副作用并清理临时值。丢弃插值结果也会执行格式化。char 先编码为 UTF-8，按字符串格式规则处理宽度和精度。

## 追加格式化

`destination.append_format(f"...")` 返回 void，需要一个直接插值表达式，允许括号。普通字符串、已经构造的 String 或带访问标记实参均不符合此形式。它不创建中间的源级插值 String。

接收者先选择一次，再求值所有插值字段，最后开始追加。格式化输入不能借用或别名指向目标 String，包括 String Read 别名；已有视图也阻止写入。`s.append_format(f"{s.len()}")` 使用独立标量快照，可以合法。原生 formatter 和调用者必须在间接别名与重入中保持这个条件。

接收者或插值字段失败会跳过追加与后续求值。格式化开始后的终止没有回滚保证。非法 UTF-8 输出、分配失败和运行时格式错误终止，不引入类型化失败。正常完成的结果保留内部 NUL，且是合法 UTF-8。

## 利用已知格式信息

普通运行时插值也可以利用编译期已知信息。编译器可以预先计算支持的内建格式片段，或将混合内建字段直接写入 String 存储。静态整数规格、浮点默认格式及常用定点/科学计数/通用精度格式，与默认格式的 str、String、bool、char 可以共同走这条路径，适用于插值和 append_format；不要求所有插值字段的值都是常量。

这些处理保留每个插值字段的必要求值与副作用。即使 `update() && false` 的最终值已知，update 调用仍要执行。运行时结果仍是独立拥有的 String，不能据此返回借用静态文本的 str。

当操作数类型和受支持的静态格式足以证明输出为合法 UTF-8 时，编译器可以省略末尾验证；其他输出继续接受运行时验证。是否使用这些处理不改变格式规则、求值顺序或错误边界。

动态文本长度在所有插值字段完成后读取，保留 String 别名的观察时机。容量界限通过检查溢出的运算合并预备字段大小和动态长度。直接写入路径无需原生格式解析或末尾 UTF-8 扫描；剩余字段不受支持时使用通用 formatter。这些是实现选择，不保证所有插值都不分配内存。

当前实现为可选文本预生成设置 64 KiB 预算。委托原生处理的剩余格式还对转义花括号和保留字段拼写计入预算；直接写入路径无需序列化原生格式串。超预算或不支持的部分继续采用运行时格式化，不因此拒绝程序。它不同于必需常量执行的限制：const 初始化不能回退运行时。此预算限制预生成工作，不限制运行时最终字符串长度。

原生自定义 formatter 可以检查整个实参集合，因此保留原始实参。已知结果也不取消必需的 owner 构造、临时值存活或清理。

## 必需常量格式化

常量初始化和 const fn 执行支持整数、bool、char、文本的默认格式，以及整数 `b/B/o/d/x/X`、十进制宽度和零填充。f32/f64 支持默认格式与 `a/A/e/E/f/F/g/G`，包括填充、对齐、符号、备用表示、零填充、宽度和精度；不使用依赖区域设置的 `L`。动态宽度和精度先求值，值须为非负整数。转换复用原生标准库，必需常量格式化受编译期资源预算约束。

```carven
const amount = f"{12.5:.2f}"; // 12.50
const title = f"build-{42:04}"; // str，内容 build-0042
const bytes = f"{'我'}".len();  // usize，值 3
```

每个常量插值结果最多 1 MiB，另有累计工作和格式嵌套预算。运行时插值仍是拥有的 String；常量初始化完成时冻结为 str。插值不能代替语法要求的普通字符串字面量或字面量模式。

## 打印

`print/println/eprint/eprintln` 无需导入，遵守普通名字查找和遮蔽。接受一个或多个 Read 值并返回 void；void、入口参数和字符迭代视图不可打印。`println()` 与 `eprintln()` 也允许零实参。

| 操作     | 流     | 结尾       |
| -------- | ------ | ---------- |
| print    | stdout | 不追加换行 |
| println  | stdout | 一个换行   |
| eprint   | stderr | 不追加换行 |
| eprintln | stderr | 一个换行   |

实参间插入一个空格，按从左到右一次求值。标量保存值，String 保留别名，视图保护 backing。文本原样输出，含 NUL；char 输出 UTF-8。`println("{value}", 3)` 输出 `{value} 3`，文本本身不是格式串。

打印不需要 `?`。缓冲和刷新遵循 C++ 标准库，不承诺每次刷新。原生格式或输出失败终止。可通过期望签名获得打印 callable，例如 `let output: fn(str, i32) -> void = println;`。

const fn 和 const test 可在支持的类型子集中直接打印。只有必需常量执行会向编译器宿主输出；普通运行时调用仍在运行时打印。已完成输出在后续失败时保留。输出字节计入累计文本工作预算。

## 结构化打印

直接 `println(value)` 显示逻辑数据结构：结构体显示源类型名和声明顺序的字段，枚举显示 `Type::Case` 与载荷，数组和切片显示方括号元素，整数区间显示边界及 `..` 或 `..=`。非空结构体、序列和枚举载荷按多行展开，每层四空格，每项以逗号结束，闭合分隔符独占一行；空结构体和序列保持 `Type {}`、`[]`。布局不依赖行宽。

嵌套文本与字符带引号和转义；顶层文本仍原样输出。指针显示地址或 `nullptr`，不解引用；外部 C++ 类型和 callable 显示 `<opaque>`。不会调用自定义 formatter、流插入操作或 getter。`println(f"{value}")` 则先执行显式格式化。打印仍检查完整值的 Read 与 backing，不添加拥有副本或转移。

根深度为零，最多展开八层，每个数组或切片最多显示 64 项，最多保留 16,384 个 UTF-8 字节（含布局空白），省略内容标记 `...`。这些上限也用于断言解释中的结构值，不限制顶层原样文本。这是诊断文本，不是序列化格式。常量块、const fn 和 const test 在其执行子集内使用同样显示规则。
