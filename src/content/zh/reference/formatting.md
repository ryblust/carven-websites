## 插值表达式

用 `f"..."` 把表达式的值插入文本。结果是独立拥有的 `String`，即使为空或没有插值字段。用 `:` 格式说明控制对齐、宽度、精度或表示方式，遵循对应的 `std::format` 规则。

```carven run
fn main() {
    let id = 42;
    println(f"ID: {id:08x}");
    println(f"{{value}} = {id}");
}
```

动态宽度和精度用嵌套插值字段，例如 `f"{value:{width}.{precision}f}"`。运行时不属于内建优化子集的格式合法性和 formatter 可用性由 C++ 检查。聚合、枚举和可调用值没有 Carven 自定义格式化协议；使用其原生表示和对应 formatter。

## 求值与读取时机

所有插值字段，包括动态格式参数，按源码顺序求值一次，然后开始格式化。插值字段是 Read 访问，不能直接写实参标记 `&` 或 `&&`；嵌套调用仍按自己的参数契约。

标量 Read 保存求值时的值；`String` Read 保留对原对象的别名，在所有插值字段求值完成后读取内容。文本视图在求值与格式化期间保持对底层存储的借用。结果拥有独立内容。

一个插值字段失败会跳过后续插值字段和格式化，保留已完成副作用并清理临时值。丢弃插值结果也会执行格式化。`char` 先编码为 UTF-8，按字符串格式规则处理宽度和精度。

## 追加格式化

`destination.append_format(f"...")` 返回 `void`，要求实参直接写成插值表达式，允许括号。普通字符串、已经构造的 `String` 或带访问标记实参均不符合此形式。它不创建中间的源级插值 `String`。

接收者先选择一次，再求值所有插值字段，最后开始追加。格式化输入不能借用或别名指向目标 `String`，包括 `String` Read 别名；已有视图也阻止写入。`s.append_format(f"{s.byte_length()}")` 使用独立标量快照，可以合法。原生 formatter 和调用者必须在间接别名与重入中保持这个条件。

接收者或插值字段失败会跳过追加与后续求值。格式化开始后的终止没有回滚保证。非法 UTF-8 输出、分配失败和运行时格式错误终止，不引入类型化失败。正常完成的结果保留内部 NUL，且是合法 UTF-8。

## 利用已知格式信息

编译器可以在编译时准备已知的格式片段，把其他值留到运行时格式化。结果仍为 `String`。各插值字段仍按源码顺序求值，保留必需的副作用和临时值生命周期。

这种可选准备有 64 KiB 工作预算。不支持或超出预算的部分继续在运行时处理，不限制最终 String 的长度；必需的 const 初始化器则必须在编译时完成，不能这样回退。

对于能提前证明 UTF-8 有效的格式，可以省略末尾检查；其他输出在运行时检查，两条路径遵循相同的格式和错误规则。原生自定义 formatter 仍接收原始实参，提供者须遵守这些值的访问和生命周期要求。

## 必需常量格式化

常量初始化和 `const fn` 执行支持整数、`bool`、`char`、单元值、文本（包括已知内容的 C 字符串）的默认格式，以及整数 `b/B/o/d/x/X`、十进制宽度和零填充。`f32`/`f64` 支持默认格式与 `a/A/e/E/f/F/g/G`，包括填充、对齐、符号、备用表示、零填充、宽度和精度；不使用依赖区域设置的 `L`。动态宽度和精度先求值，值须为非负整数。转换复用原生标准库，必需常量格式化受编译期资源预算约束。

```carven
const amount = f"{12.5:.2f}"; // 12.50
const title = f"build-{42:04}"; // String，内容 build-0042
const bytes = f"{'我'}".byte_length();  // usize，值 3
```

每个常量插值结果最多 1 MiB，另有累计工作和格式嵌套预算。运行时插值结果仍是拥有独立内容的 `String`；常量初始化完成后仍保留 String 类型和所有权。插值不能代替语法要求的普通字符串字面量或字面量模式。

## 打印

`print`、`println`、`eprint` 和 `eprintln` 接受一个或多个 Read 值并返回 `void`；单元值和字符迭代视图不可打印。`println()` 与 `eprintln()` 也允许零实参。它们的[模块绑定](/zh/reference/modules/#标准模块与默认名字)遵循普通名字查找规则。

| 操作       | 流       | 结尾       |
| ---------- | -------- | ---------- |
| `print`    | `stdout` | 不追加换行 |
| `println`  | `stdout` | 一个换行   |
| `eprint`   | `stderr` | 不追加换行 |
| `eprintln` | `stderr` | 一个换行   |

实参间插入一个空格，按从左到右一次求值。标量保存值，`String` 保留别名，视图保护底层存储。文本原样输出，含 NUL；`char` 输出 UTF-8。`println("{value}", 3)` 输出 `{value} 3`，文本本身不是格式串。

打印不需要 `?`。缓冲和刷新遵循 C++ 标准库，不承诺每次刷新。原生格式或输出失败终止。可通过期望签名获得打印可调用值，例如 `let output: fn(str, i32) -> void = println;`。

`const fn`、常量块和 `const test` 可在支持的类型子集中直接打印，C 字符串按文本输出。只有必需常量执行会向编译器宿主输出；普通运行时调用仍在运行时打印。已完成输出在后续失败时保留。输出字节计入累计文本工作预算。

## 结构化打印

直接 `println(value)` 显示逻辑数据结构：结构体显示源类型名和声明顺序的字段，枚举显示 `Type::Case` 与载荷，数组和切片显示方括号元素，整数区间显示边界及 `..` 或 `..=`。非空结构体、序列和枚举载荷按多行展开，每层四空格，每项以逗号结束，闭合分隔符独占一行；空结构体和序列保持 `Type {}`、`[]`。布局不依赖行宽。

嵌套文本与字符带引号和转义；顶层文本仍原样输出。类值只显示类型名，嵌套时也是如此，从不展开私有字段。

原生结果按其 C++ 类型分类：

| C++ 类型                            | 显示                                                          |
| ----------------------------------- | ------------------------------------------------------------- |
| 算术类型                            | 标量值                                                        |
| `char32_t`                          | 字符，嵌套时带引号                                            |
| `char8_t`、`char16_t`、`wchar_t`    | 数值码元                                                      |
| `std::string_view`、运行时 `String` | 带引号文本                                                    |
| `char*`、`const char*`              | 按文本规则；空值显示 `nullptr`，非空值要求可读的 NUL 结尾存储 |
| 其他可转换为 `const void*` 的指针   | 地址或 `nullptr`，不解引用                                    |
| 其他外部类型、函数指针、可调用值    | `<opaque>`                                                    |

```carven run
class Token {
    id: i32,
    fn create(id: i32) -> Token => { id: id };
}

struct Entry {
    token: Token,
    name: str,
}

println(Entry { token: Token::create(7), name: "seven" }, [c"7"]);
```

```text
Entry {
    token: Token,
    name: "seven",
} [
    "7",
]
```

不会调用自定义 formatter、流插入操作或 getter，嵌套字段也一样。`println(f"{value}")` 则先执行显式格式化。打印仍检查完整值的 Read 与底层存储，不创建拥有所有权的副本，也不转移值。

根深度为零，最多展开八层，每个数组或切片最多显示 64 项，最多保留 16,384 个 UTF-8 字节（含布局空白），省略内容标记 `...`。这些上限也用于断言解释中的结构值，不限制顶层原样文本。这是诊断文本，不是序列化格式。常量块、`const fn` 和 `const test` 在其执行子集内使用同样显示规则。

类型擦除指针接受空格式或 `p`；静态执行输出 `const@nonnull` 或 `const@null`，解释与原生执行按各自上下文显示地址。元组和 `Vector` 采用相同的结构化显示深度、元素数量及字节上限。
